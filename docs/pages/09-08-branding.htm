Branding

Logo, title and environment label.

For: Administrators (globeadmin, admin roles)

Settings → Look → Branding (start page tile Branding; globeadmin or the admin role right Branding) gives this installation its own look – on the sign-in pages and in the top bar:

  • Logo and optional logo for dark mode: PNG, JPG, WebP, GIF or SVG up to 512 KB, any aspect ratio (at most 32 px high in the top bar, 72 px on the sign-in pages). They are stored in nuBuilder Forte's file table zzzzsys_file (codes nunext_logo and nunext_logo_dark), so they are part of backups and App cloner copies and can also be replaced in Forms → Files. If a logo is deleted there, nuBuilder Next's logo is shown again. An SVG logo is always served with a sandbox policy, so script inside it cannot run.
  • Show logo: everywhere (top bar and sign-in pages), only on the sign-in pages, or nowhere – for the own logo and nuBuilder Next's. The globeadmin can also right-click the logo in the top bar: after a confirmation it is hidden there (the setting becomes only on the sign-in pages), and a message says where to show it again. Without a logo in the top bar the title stands there when it is switched on (below), and a Home button () sits at the very left of the bar; on a computer screen the page's breadcrumb (e.g. Settings / IP access) stands right next to it instead of above the page. On phones such a bar is compact: search and bell stay in the bar (theme and language move to the top of the user menu), there is no ☰ menu to open (and no pin) – the user menu's button shows ☰ and opens the user menu directly (for users with links in the bar: those links too).
  • Title: the name of the application – in the browser tab, on the sign-in page and (below) in the top bar. Empty = the setting $nuConfigTitle (shown as the placeholder); a title typed here wins over it (nuBuilder Forte keeps showing its own).
  • Title on phones and Show the title on phones: on screens narrower than 576 px the top bar shows this title instead – with its own switch, independent of the one for larger screens. Empty or switched off = no title on phones, so the bar keeps its room for the buttons.
  • Show the title next to the logo – Show the title in the top bar while the logo is not shown there: the title in the top bar.
  • Use the logo as browser icon instead of nuBuilder Next's icon (square logos work best).
  • Accent colour and the other colours are part of the themes (Settings → Look → Themes); an accent colour set here before is kept as the own theme "My theme".
  • Environment label, e.g. TEST or DEV, with its own colour: a badge in the top bar and on the sign-in pages, a line of its colour at the top of every page and [TEST] in the browser tab title – so a test copy is not mistaken for the live system. $nuConfigEnvironmentLabel and $nuConfigEnvironmentColor in nuconfig.php take priority over the page (the field is then read-only): the label belongs to the server, and a database copied to a test server with the App cloner would otherwise bring the label of the server it came from. Example: $nuConfigEnvironmentLabel = "TEST"; $nuConfigEnvironmentColor = "#e67e22";
  • The preview on the page shows logo, title, colours and label before saving. Reset removes the logos and all branding settings. Error pages and the installer always use nuBuilder Next's look; a login page from $nuWelcomeBodyInnerHTML keeps its own HTML (accent colour and label apply). nuBuilder Forte (4.x) itself is not affected.

Installable app

Phones, tablets and computers can install nuBuilder Next as an app: its own icon on the home screen or in the start menu, its own window without the browser's bars, and a faster start, because the program's files (styles, scripts, icons) are kept on the device. Chrome, Edge and Android offer Install in the browser; the user menu then shows Install app. On iPhone and iPad, Safari has no install button – Install app explains Share → Add to Home Screen.

  • Name and colour come from this page: the title (the phone title as short name) and the accent colour.
  • Icon: the logo, on a white square, when Use the logo as browser icon is on; otherwise nuBuilder Next's icon.
  • Shortcuts: a long press on the icon lists the user's first favourites of the start page.
  • Offline: pages and data always come from the server – nothing is stored on the device for reading. Without a connection the app shows a short page with Try again instead of the browser's error.
  • Switch: Installable app on this page (on by default). Switched off, browsers no longer offer the install, and an app already installed removes its stored files on the next visit.

Installing needs HTTPS (or the server's own computer). Each installation in its own folder installs as its own app. Updates need nothing: a new version brings new files, and the old ones are dropped.
