List views

Columns, sort and phone layout of nuBuilder Next's own lists.

For: Everyone

All of nuBuilder Next's own lists – Users, Access levels, Permission items, Forms, Procedures, Reports, Files (tiles or table), Items, Translations, Prompt generator, Log, Audit trail, E-mail log, E-mail templates, SQL builder, custom user fields, admin roles, API clients, notifications, dashboards, webhooks and their calls, data exports and the self-test results – can be shown in different views – the button in the title bar shows the current view and switches between them.

  • A view sets the columns and their order, the width (auto, narrow, wide) and alignment of each column, the sort, the rows per page, which filters are offered with their default values, whether the filters start open – and, separately, what a phone shows: below 768 px every row is a card with a title, a badge on the right and up to four lines (label: value) – or, with On phones: Table (tab Phone of the editor), the table: tighter, the first column stays while the others scroll sideways.
  • Cards or table on your phone: the / button next to the view menu (phones only) switches the list between cards and table. The choice is kept on this device for this list; switching back to the view's own layout removes it, so the list follows its view again.
  • Standard views: Default, Compact and All columns – fixed; New view… starts from the current view. The users list also offers created, last changed, last login, authenticator app, admin role, online now, password changed, status, valid until, language and more; filters for department, team, language, last login, valid until, authenticator app, online and admin role.
  • My views: everybody who may open the list can save personal views and choose one as my default (Set as my default; Use the list’s default again removes it).
  • Shared views (the globeadmin and admin roles with the right List views): visible for everyone or only for the ticked access levels (e.g. an HR view for the access level hr on top of the common views). Set as default for everyone makes a view the list's default – at first it is Default. Share a copy with everyone turns a personal view (also another user's, listed under Personal views of other users) into a shared one. Export shared views / Import views… move them as JSON to another installation (access levels by code; views with the same name are replaced).
  • Further columns and filters, e.g. forms: table filter; procedures: category, template, run by everyone; items: category, language, form, sort order; log and e-mail log: a period (last 7 / 30 / 90 days) besides the dates; e-mail log: tag and sender. Files also has the display Tiles (the thumbnails, its default) or Table. Debug results keep their own message list.
  • Which view opens: the one in the address (&view=…; translations: &lv=…, because view is the tab Missing there), else the own default, else the list's default, else Default. Links of the list (sort, pages, Print) keep the view; Print, Export CSV and Excel use its columns in its order.
  • Stored in zzzzsys_nunext_list_view; the list default in zzzzsys_nunext_setting (listview_defaults), personal defaults in the user's sus_json (NUNEXT_LIST_VIEWS). Columns and filters are defined in core/nulistdefs.php – never free SQL. Saving, deleting, defaults and imports of shared views are logged.
