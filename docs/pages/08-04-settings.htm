Settings

Advanced nuBuilder's settings table (Setup → Settings).

For: Administrators (globeadmin, admin roles)

On screens narrower than 800 px the column Description is hidden; the (i) next to a setting's title shows its description on tap or click.

Admin tools → Settings (globeadmin) edits nuBuilder's settings table zzzzsys_config – the same rows as nuBuilder's Setup form. $… settings are PHP variables of nuconfig.php; the others are JavaScript options (nuUXOptions['…']).

While $nuConfigSettingsFromDB is not true, a notice above the list says the settings are not used; its button Use these settings sets $nuConfigSettingsFromDB = true; in nuconfig.php after a confirmation (same checks and backup as Configuration file) and reloads the page.

  • Search (title, setting, value, description), category, and filter buttons with counts (All · Used · Not yet · Not needed) by what a setting means for nuBuilder Next. Each of nuBuilder's settings has a tag after its title (the reason on hover): Used – nuBuilder Next reads it ($nuConfig2FAAdmin, $nuConfig2FAUser, $nuConfigDemoSavingAllowedIds, $nuConfigIsDemo, $nuConfigGlobeadminHome, $nuConfigIncludeApexCharts, $nuConfigTitle, nuDebugMode, nuHideTabTitleIfOnlyOne); Not yet – not built yet, only nuBuilder uses it for now (e.g. sticky browse headers, close after save, user form labels, keep session alive); Not needed – nuBuilder Next has its own solution or it is always on (form title icons → ⋮ menu, updater and backups, session timeouts, keeping the session alive (sessions end only after the inactivity timeout; every click counts), two-factor e-mail code, Ace / Select2 themes, TinyMCE and Google Charts loaded automatically). The list is NuSettings::STATUS in core/nusettings.php. $nuConfigTitle (as in nuBuilder) names the application: it replaces "nuBuilder Next" in the browser tab ("Forms · title") and appears above Sign in on the login page. true / false settings are a selection, numbers a number field, the Ace theme a list of themes; known values are suggested.
  • Changed values are marked and Save turns red; only changed values are stored and logged (Settings changed). marks settings nuBuilder applies only after a new login or a browser restart.
  • Import copies the values set in nuconfig.php into the table (as nuBuilder's Import button): PHP variables and nuUXOptions['…'] = …; lines (also inside nuBuilder's $nuJSOptions); commented lines are skipped, settings that nuconfig.php does not set stay as they are. Only possible without unsaved changes.
  • If the table is missing (database set up with nuBuilder Next's own install scripts, older nuBuilder), the page names the database and the database's message and offers Create settings table: the table as in nuBuilder with nuBuilder's default settings. The installer now creates it too.
  • The table is used only with $nuConfigSettingsFromDB = true in nuconfig.php (nuBuilder's setting): its values then replace those of nuconfig.php – in nuBuilder Next from the next page on, as typed values (no eval). Database access, $nuConfigSecretKey and the switch itself always come from nuconfig.php.
