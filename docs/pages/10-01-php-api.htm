Input objects of type nuAutoNumber get the next number when a new record (or subform row) is saved (last number + 1, a prefix like INV is kept; design mode shows the last number under Last number, new records show “assigned on save”). Input objects of type nuScroll: the arrow keys ↑ / ↓ step through the list of the object's Scroll property (JavaScript, e.g. ['Low', 'Medium', 'High']) and start over at the end; a value that is not in the list can still be typed. The same list is offered as suggestions – on a phone tapping the field shows it, on a desktop a small arrow in the field opens it. Excel export (NuXlsx)

Exports without code – tables, views and queries to Excel or CSV, saved and run again – are the Data export. In code, the class NuXlsx writes .xlsx files without other libraries – in procedures, PHP hooks and page forms ($nu->excel()). Values keep their type: numbers stay numbers, DateTime becomes an Excel date, true / false a boolean, strings are always text (a string starting with = never becomes a formula – formulas only with NuXlsx::formula()).

$x = NuXlsx::create('Orders');                       // or $nu->excel() in a page
$s = $x->sheet('Open orders');                       // more sheets: $x->sheet('…') again
$s->header(['Customer', 'Amount', 'Date'])           // bold, frozen below, autofilter
  ->rows($rows)                                       // arrays of values
  ->row(['Total', NuXlsx::formula('SUM(B2:B99)')], ['bold' => true])
  ->style('B2:B100', ['format' => '#,##0.00'])
  ->row([NuXlsx::cell('late', ['color' => '#c00000', 'bg' => '#fff3cd'])])
  ->width('A', 30);                                   // other columns: width from the content
$x->download('orders.xlsx');                         // or $x->save($file) / $x->toString() (e-mail attachment)

Styles: bold, italic, underline, strike, size, font, color, bg (#RRGGBB), format (Excel number format, e.g. 0.00, dd.mm.yyyy, 0%), align (left / center / right), valign, wrap, border (thin / medium / thick / dashed / dotted / double). Sheet: bold($range), merge($range), freeze('B2'), filter($range), widths([30, 12]), height($row, $points), rightToLeft(), numbersFromText() (text such as "12.5" becomes a number). Workbook: title(), author(), subject(), company(), dateFormats('dd.mm.yyyy', 'dd.mm.yyyy hh:mm') (default: Excel's date format in the reader's language). The lists' print views have Export Excel next to Export CSV (only the visible columns).
