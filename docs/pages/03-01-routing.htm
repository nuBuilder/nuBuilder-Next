Request routing

index.php, the route table, api.php, cron.php and the other entry points.

For: Administrators (globeadmin, admin roles)

index.php and the route table

Every page is index.php?p=<route>; without p it is the start page (home). index.php holds a table of all routes; each route has options:

  • public – no login needed (login, logout, two-step login, forgot / reset password, language, branding images, report files of the REST API).
  • json – a background endpoint (e.g. formapi, builderapi, notifyapi, dashboardapi): without a session it answers 401 with JSON instead of redirecting to the login page.

An unknown route answers 404. After the checks below the file pages/nu<route>.php runs – e.g. ?p=form → pages/nuform.php.

Checks before a page runs

  1. No nuconfig.php yet → the installer.
  2. nu_boot() – configuration, security headers, session (see Startup).
  3. nuBuilder Forte's auto-login link (index.php?u=…) is handed to pages/nuautologin.php.
  4. Every POST must carry the page's CSRF token (form field _csrf or header X-CSRF-Token).
  5. Routes that are not public need a signed-in user; otherwise the address is remembered and the login page opens (JSON routes: 401).
  6. During an update only the globeadmin (and admin roles with the right Update) may work; everybody else gets 503.
  7. Demo users may look but not write; a globeadmin acting as a user in view only mode cannot post.
  8. A user who must change his password is sent to ?p=password; the globeadmin is sent to the setup wizard once while it is pending.

Background requests that should not count as activity (the bell, the "also open" ping, a page's poll with ?passive=1) are marked passive, so they do not keep an idle session alive.

The form API

Edit forms and lists talk to index.php?p=formapi (POST, CSRF header). Actions: save, delete, lookupid, lookupcode, php (nuRunPHPHidden), refresh, props, global, hash / hashfields (hash viewer, globeadmin), presence and report. Every answer is JSON with ok and, on failure, errors (message and field).
