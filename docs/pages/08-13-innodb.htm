Storage engine (InnoDB)

Advanced Converting old MyISAM tables.

For: Administrators (globeadmin, admin roles)

All tables should use InnoDB (transactions, row locking, crash safety). nuBuilder Next creates every new table – its own, the ones of new forms and nuCreateTableFromSelect() – as InnoDB, whatever $nuConfigDBEngine says. Older nuBuilder databases often still contain MyISAM tables.

  • System status → Storage engine lists every table that is not InnoDB with its engine and approximate row count.
  • Convert all to InnoDB runs ALTER TABLE … ENGINE=InnoDB table by table. Tables that fail are listed; the others are converted. Make a backup first; large tables take time.
  • Keep $nuConfigDBEngine = "InnoDB" in nuconfig.php: nuBuilder's update converts its system tables to that engine.
