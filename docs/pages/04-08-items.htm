Items

nuBuilder's item lists.

For: Users with rights on: nuitem

Forms → Tools → Items: nuBuilder's item list (zzzzsys_item) – values with description, group, category, linked object, sort order, tags, language and two additional fields. The list shows active items by default; switch the filter to see inactive ones. Items starting with nu belong to nuBuilder and are hidden for non-administrators.
