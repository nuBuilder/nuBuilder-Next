Editing records

Saving, required and unique fields, masks, cloning and deleting, sub-forms and lookups, keyboard shortcuts.

For: Everyone

Editing a record

  • Save, Clone and Delete look the same (light buttons with icon and text, as in nuBuilder Forte (4.x)). As soon as you change something, Save turns red – red text on a light red background: there are unsaved changes. After saving it looks like the others again. On phones the three show only their icon.
  • The row with the breadcrumb and the buttons (Back, Save, Delete …) stays at the top of the screen while you scroll down – on form pages and on nuBuilder Next's own edit pages, on computers and phones.
  • After saving, deleting or cloning, a short message appears at the bottom right.
  • Tabs: a record opened from the list (or a link) starts on its first tab. After saving or reloading the page, the tab you were on stays open.
  • On phones, Save, Clone and Delete show only their icon (Save as a floppy disk); the text appears as tooltip.
  • Required fields are marked with *, fields whose value must be unique with a key (see Markers after labels below). If something is missing or invalid, a message tells you which field, and the field is highlighted. On nuBuilder Next's own pages (users, access levels, webhooks …) the message Please check the highlighted fields can be clicked: it lists the fields with their messages, and a click on one opens its tab or folded section and puts the cursor there.
  • Fields with a mask (e.g. IBAN, phone) only accept the expected characters; the separators are added for you.
  • If you leave a record with unsaved changes, the browser asks first.
  • Ctrl+Shift+S (Mac ⌃⇧S) saves – in forms and on nuBuilder Next's own edit pages (user, access level, procedure, prompt, e-mail template …), also while you are typing in a field; the tooltip of the Save button shows it.
  • Fields with a suggestion list (an arrow on the right, e.g. Position, Department, Team) offer values to choose: type to filter, or click the arrow to see all values – also when the field already has one (the old value comes back if you pick nothing).
  • Searchable selects open their list above everything else; in multiple selects the chosen values are shown as tags, the field grows when they need more lines.
  • Some fields have a small help icon ? on their right: point at it (or tap it) to read a hint.

Clone and delete

  • Clone copies the record into a new, unsaved record. A yellow badge Clone – not saved yet and a dashed yellow frame show that you are working on the copy. Nothing is stored until you click Save. The editors of nuBuilder Next itself (users, access levels, procedures, reports, SQL builder, permission items, e-mail templates, files, items, prompts, Form cloner and App cloner settings) work the same way: Clone opens the copy with a free code, its access levels and stored content (report layout, file, query), the badge and a red Save.
  • Delete asks for confirmation and then returns to the list.

Sub-forms, lookups, files

  • Sub-forms (rows inside a record): typing in the empty last row adds a new row; switch Delete on to remove a row when saving.
  • Lookups: type a code or click the search button to pick a record from a list. With a description width of 0 (design mode) only the code is shown.
  • Markers after labels: a red * means the field must not be empty, a key means its value must be unique – no other record may have the same value (both can appear: * 🔑). Hover or focus the key for its meaning (required and unique, or unique only); the * says "Required field". They come from the object's Validation setting (No blanks / No duplicates / No duplicates and blanks), also in subform column titles, and are not shown when the form can only be viewed. $nuConfigValidationMarkers = false in nuconfig.php switches them off. nuBuilder Next's own pages show the key at their unique fields too – login name and code of users, codes of access levels, procedures, reports, files, dashboards, prompts, SQL builder queries and custom user fields, permission item idents, the code of a new form.
  • Files: choose a file to upload; download or remove it with the buttons next to the field.
  • Breadcrumbs (top left) show where you came from; click an entry to go back.

Keyboard shortcuts and the options menu

The ⋮ button at the end of the toolbar opens the options menu with the actions that have no button of their own, each with its keyboard shortcut. Save, Clone, Delete, Add, Print, Search, Arrange objects, Form info, Form properties, Object list and Log out are not in the menu – they have buttons on the page (Log out: the user menu at the top right) – but their shortcuts still work. All shortcuts are Ctrl+Shift+key:

  • S save (in a list: search; also on nuBuilder Next's own edit pages), C clone, Y delete, A in a list: add a record, P print the list, R refresh, ? help, L log out.
  • ← → previous / next tab (in a list: page), Home / End first / last page, 1–9 in a list: switch a column in or out of the search.
  • Only what you are allowed to do is offered – a shortcut for something you have no right for does nothing.
  • Mac: use Control+Shift (shown as ⌃⇧). Cmd+Shift also works, except for combinations macOS or the browser keeps for itself (⌘⇧Q logs you out of macOS!).
