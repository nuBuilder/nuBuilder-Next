Form rendering pipeline

From the form's metadata to the HTML of a list or an edit form.

For: Administrators (globeadmin, admin roles)

index.php?p=form&f=<form id or code> shows a form's list; with &r=<record id> (or -1 for a new record) its edit view. Both are drawn on the server by pages/nuform.php:

  1. Metadata – NuFormMeta::load() reads the form, tabs, objects, events, list columns and hooks (a draft instead, while its author previews it). Rights are checked with NuAcl: view, and per action add, save, delete, clone, print; nuBuilder's "browse only" / "edit only" and "no changes to existing records" of the access level apply.
  2. Hash – NuHash::forForm() collects the hash variables: user, record, fields of the record, form properties.
  3. Hooks – Before Browse or Before Edit run (after the global hook), and may add JavaScript, set values or properties, or stop with an error.
  4. Data
    • List: NuBrowse::query() keeps FROM / WHERE / GROUP BY / HAVING of the browse SQL, selects the primary key and the list columns, and wraps it for search, column filters, count, sort and paging – on MySQL and SQL Server.
    • Record: NuRecord::load(); sub-form rows come from the sub-form's browse SQL filtered by the foreign key; lookups show code and description from the lookup form.
  5. Field data access – fields the user may not see are left out or masked before anything is sent to the browser.
  6. HTML – NuRender writes tabs and objects with nuBuilder's element ids (#cus_name, #label_cus_name, #<lookup>code, #<subform>000<field>, #nuTab0 …), so existing JavaScript finds its targets. The layout is chosen per form: absolute (nuBuilder's pixel positions), auto (rows derived from the positions, Bootstrap columns) or grid (explicit rows and spans).
  7. Properties – the page gets a scope key; values set with nuSetProperty() in PHP stay on the server and cannot be changed in the browser (NuProps).
  8. Browser – assets/js/nu/nuruntime.js and the compatibility functions start, run nuBuilder's load hooks and the form's JavaScript, and from then on talk to the form API.
