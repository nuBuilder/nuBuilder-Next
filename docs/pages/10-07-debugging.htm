Debugging

Finding errors in your own code.

For: Administrators (globeadmin, admin roles)

  • nuDebug($a, $b, …) writes to Log → Debug (nuBuilder format). nuDebug::setFlag('import')->log(…) sets a flag to filter by.
  • $nuConfigDebug = true shows database errors on screen – only for testing.
  • Form pages allow inline scripts (needed for form code); all other pages use a strict Content-Security-Policy. Forms with charts (or nuChart in their code) also allow www.gstatic.com for Google Charts.
