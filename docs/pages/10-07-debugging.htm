Debugging

Finding errors in your own code.

For: Administrators (globeadmin, admin roles)

  • nuDebug($a, $b, …) writes to Log → Debug (nuBuilder Forte (4.x) format). nuDebug::setFlag('import')->log(…) sets a flag to filter by.
  • A red bug next to the bell shows that new Debug results were written – by nuDebug(), a failing query of a field, an error in form code and the like. It shows the number, and a click lists the newest entries. It appears only while there is something new, and only for users who may open Debug results. Mark as read or opening Log → Debug makes it go away. It looks again every minute and right after a button or a save of a form talked to the server.
  • $nuConfigDebug = true shows database errors on screen – only for testing.
  • Form pages allow inline scripts (needed for form code); all other pages use a strict Content-Security-Policy. Forms with charts (or nuChart in their code) also allow www.gstatic.com for Google Charts.
