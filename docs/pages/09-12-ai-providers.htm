AI providers

Let the AI dialogues send their prompt to an AI service and fetch the answer themselves – in addition to copy and paste.

For: Administrators (globeadmin, admin roles with the right AI providers)

Every AI dialogue of nuBuilder Next – Forms with AI, Ask AI in design mode, Reports with AI, the draft of a help page, translations and the prompt generator – works by copying a prompt into an AI chat and pasting the answer. With an AI provider set up, the same dialogues also show Ask AI: the prompt is sent from the server to the service, and the answer lands in the answer box. From there on nothing changes – the answer is checked, the plan and the preview are shown, and only Apply / Create / Insert stores anything.

Set up a configuration

  1. AI providers (start page tile, Settings → Logs & integration, index.php?p=aiproviders) → Add.
  2. Service: Anthropic (Claude), OpenAI-compatible or Google Gemini. OpenAI-compatible covers OpenAI itself, Azure OpenAI, Mistral, OpenRouter and local models (Ollama, LM Studio) – enter their address; for the three services themselves leave it empty.
  3. The API key from the service's console. It is stored encrypted (with the secret key of the configuration file) and never shown again; leave the field empty later to keep it.
  4. Fetch models asks the service for its models; pick one or type its name.
  5. Test saves and sends a one-line request – the result shows the time and the tokens used.
SettingWhat it does
Temperature0 to 2. Low values give exact, repeatable answers – right for forms and reports. Empty = the service's default (some models accept nothing else).
Max. answer lengthIn tokens. A whole form or report needs room – 8,000 or more. An answer cut at the limit is reported next to Ask AI.
TimeoutHow long to wait, 10 to 900 seconds. A large report or small app can take a minute or two; the web server's own limit for one request must be at least as long.
Monthly token limitTokens in + out per calendar month. Once reached, requests with this configuration are refused until the next month.
Extra instructionSent with every request as system instruction, e.g. "Field labels in German."
Extra parametersA JSON object merged into the request, for settings of the service not offered here ({"top_p": 0.9}). A value of null removes a parameter the page would send.

A local model runs on a private address (http://localhost:11434/v1 for Ollama). Switch on Allow private addresses below the list for that; otherwise only https addresses on the public internet are called, and redirects are never followed.

Who may use a configuration

The dialogues keep their own rights – only someone who may design forms sees Form with AI at all. On top of that each configuration says who is offered it:

  • Everyone who can open the AI dialogue.
  • Chosen access levels – a user needs one of them (the main level or an additional one). The globeadmin always may.
  • Whoever knows the password – the dialogue asks for it once per session, in place of Ask AI. Five wrong passwords lock the question for 15 minutes; a new password locks the configuration again for everyone.

The password also protects the API key. In a password-protected configuration the key is encrypted with the password (at least 12 characters) on top of the server's secret key. Nobody can use or read it without the password – not from the database or a backup, and not an administrator who does not know it. What follows from that:

  • A forgotten password cannot be reset. Enter the API key again together with a new password.
  • On the configuration's own page a bar shows whether it is locked. Enter the password there to Test, Fetch models, change the key, set a new password or switch to another access rule. Whoever sets the password is unlocked at once.
  • Choose a long password: someone who steals a database backup can try passwords without any limit.
  • No hash of the password is stored – a wrong password simply fails to decrypt. After unlocking, the key needed for decrypting stays in the session, itself encrypted with a random value that only the browser keeps in a cookie; neither the session file nor the cookie alone opens anything. It ends with the session.
  • This protects the stored key. It cannot protect against someone who can change the program files on the server while a session is unlocked.
  • Needs PHP's sodium extension with Argon2; without it the password rule cannot be chosen.

With several configurations the dialogue shows a select; the last one used is remembered in the browser. An inactive configuration is offered to nobody.

Ask AI in the dialogues

  • Describe what you want as before, then Ask AI instead of Copy prompt. While the service works, Cancel stops waiting.
  • The answer is put into the answer box and checked at once. If the check finds errors (an unknown column, a missing size), they are sent back to the AI once, and the corrected answer is checked again. If errors remain, they are listed – ask again or edit the answer.
  • The help page draft, translations and the prompt generator have no such check: the answer is put into the answer box (the prompt generator shows it below the prompt) and you go on as with a pasted answer.
  • What is sent: the prompt – your description, the structure it lists (tables, columns, the current form or layout) and nothing else. The context file is not sent; data rows only where a dialogue lets you tick them into the prompt.

Usage and safety

  • Every request is recorded: time, user, where it was used, model, tokens in and out, duration, and the error when it failed. The content of prompts and answers is never stored. The list shows requests and tokens of the month; a configuration's page shows its last requests. Rows are kept for 400 days.
  • The request runs on the server; the API key never reaches the browser.
  • Saving, deleting and testing a configuration, and wrong passwords, are written to the log.
  • In demo mode there are no AI requests.
  • Without the PHP extension curl no request can be sent; without a secret key in the configuration file the API keys are stored unencrypted (the list says so).
