Start page of the globeadmin

Tiles, groups, layouts and appearance of the administrator's start page.

For: Administrators (globeadmin, admin roles)

The globeadmin's start page shows tiles in groups (Users & rights, Development, Communication) and also the admin tools in the groups System (Update, Security check, Settings, nuconfig.php, Setup wizard, System status), Look (Branding, Dashboards), Data (Database, File Manager, CSV import, App cloner, Sample data) and Integration (API clients, Prompt generator, Compatibility check). With display Tabs they sit in their own tab Admin tools. Badges show when a newer sample data set is available and how many points of System status need a look. Start pages customized in older versions get these groups once at the end (only tools not placed yet) – move, rename or hide them like any other group. A click on a tile opens its page. Some tiles have a button on the right instead of the arrow: + opens a new record straight away (Users, Permission items, Procedures, Prompt generator, Notes), ▾ opens a menu with the pages behind the tile (Access levels: new access level, start pages of users · Forms: new form, cloner, CSV import, code snippets, items, files, formats, translations · API clients · E-mail · Log · Database). Customise (next to the search) changes the layout shown – an own one or, with the right Start page layout, a shared one (see Saved layouts); View changes how the tiles look (below).

User Home: the house icon next to ☆ in the search row opens nuBuilder Forte's launch form User Home with the buttons the New form wizard places there (also in the user menu and as a tile).

Customise (one button next to the search) opens a panel on the right (on phones from the bottom) with three tabs, the last one used is opened again (at first: Appearance): Appearance – how the tiles look (key V opens this tab, Esc closes); Content – Edit tiles and groups starts the edit mode described below (users: Personalise); Layouts – choose, save, rename, share and delete layouts. Each setting is in one place only: the tile style is no longer in the edit bar.

Appearance changes how the tiles look – at once, without reloading the page. Tile style: Large, Cards, Compact, List (1, 2 or as many columns as fit; with one column a readable or the full width), Launcher (big icons), Panels (one card per group with links; + and ▾ at the end of a row), Table (rows with description, group and status – a click on a column title sorts; the sorting is not saved). Descriptions: Auto (on the tile where there is room, otherwise – or when the text is cut – a tooltip), Always, Tooltip, Hover card (description, badge and the pages behind ▾), Info icon (ⓘ on each tile), Off; how many lines and how long the mouse must rest. Keyboard focus shows the same tooltip; on touch screens a long press (the tile then does not open). Navigation: Groups (one below the other), Tabs, Sidebar (one group at a time; on narrow screens a drop-down list), No groups (all tiles in one block). While you search, all groups are shown. On top of the page: a row with your favourites and a row with the tiles you opened last (also those opened with Ctrl+K). Look: density, icons (soft, solid, outline, grey, plain), a colour per group, badges, the quick actions + and ▾. Reset view goes back to the defaults.

Settings for: All screen sizes or Only the current one – phone (narrower than 576 px), tablet (narrower than 992 px) or desktop; it is the width of the start page, not the device. A size with own settings says so and offers Use the same as all sizes. A layout without own phone settings shows a one-column list on phones, and tabs there become the sidebar. With navigation Tabs or Sidebar, Use for: Only “…” gives the open tab a style of its own (another tab may stay Cards while “Admin tools” shows Panels). Where a change goes: on a personal layout into the layout. On a shared layout into your own view of it – tiles, groups and tabs keep coming from the layout, so later changes by the administrator still arrive; Undo my changes goes back to the layout's view. With the right Start page layout the panel asks each time it opens: Only me (the default) or Everyone using “…” – then a yellow note is shown and the first save offers Undo; Make my view the layout's view copies your own view into the layout. Own views are kept per layout (users in sus_json, key NUNEXT_HOME_VIEW; the globeadmin in the setting home_view_ga; demo visitors for the session), for at most 20 layouts. Layouts saved by older versions keep their look: their tile size becomes the style (Large, Compact, List, Wide list = List with full width, List in 2 columns), the display Groups / Tabs the navigation.

Favourites: in Customise the of a tile marks it as a favourite ( = favourite, click again to remove); they are part of the layout. The button Favourites next to the search on the start page then shows only those tiles – groups and tabs without a favourite are hidden; while you search, all tiles are searched. The choice is kept per login (globeadmin: for the installation's globeadmin). Without favourites the button is greyed out. In Customise favourite tiles keep a in the corner, and the button Favourites in its bar shows only them and their groups while you edit (it starts as on the start page; it is a view filter and is not saved).

  • Saved layouts (in Customise → tab Layouts; Changes apply to – only me or everyone using the layout – is on the tab Appearance): the list shows the layouts – a click switches at once (it becomes your layout until you choose another). Save as new layout… starts from Based on: the current layout (a copy, as before) or one of the profiles below – with a profile the dialog shows its description and numbers, Take my own tiles along moves your own tiles into the new layout's group “My tiles”, and the name is the profile's until you type one; the current layout stays as it is (name; with the right Start page layout also Shared and, for shared layouts, the admin roles that see it – none ticked = every admin). + = Save as new layout; ⋯ = Name and visibility…, Delete layout and – for shared layouts – Set as default for everyone (the list marks it as default). Everybody with the admin start page may save and customise own layouts; shared layouts are changed only with Start page layout. The single layout of earlier versions became the shared layout Standard, the default for everyone. Stored in zzzzsys_nunext_list_view (list home), like the list views.
  • Search (field above the tiles, / jumps into it): filters the tiles as you type – label and description, in the current language and in English (Benutzer and users both work). More results below it lists what matches but is no tile: pages and actions of the tiles' ▾ menus, own tiles, forms, procedures and reports. Enter opens the first hit, Esc clears the field.
  • Pin: every entry of a tile's ▾ menu (e.g. Forms → Formats, E-mail → E-mail log, API clients → API playground) has a pin on the right: one click puts it on the start page as a tile of its own, right after its tile; a second click takes it off again. In Customize → Add tile the type Page of nuBuilder Next lists every tile, page and action that is not on the start page yet.
  • Ctrl+K (or the magnifier in the top bar, on every page, globeadmin only): a search box for pages, actions, own tiles, forms, procedures and reports – ↑ ↓ choose, Enter opens, Ctrl+Enter in a new tab, Esc closes. With an empty box it shows the entries opened last (kept in this browser).
  • Edit mode (Customise → Content → Edit tiles and groups; offered when you may change the current layout) turns the start page itself into edit mode: the tiles stay where they are and get small tools; a bar at the top holds display, Add group, Add tile, Start from, Cancel and Done. Done saves everything at once, Cancel discards the changes (it asks first). Start from ▾ (in place of Reset) lists the profiles; a click replaces the page you are editing – a blue strip says what was loaded and has Undo; nothing is saved until Done, Cancel goes back to the saved layout. Keep my own tiles (on by default) moves your own tiles into a group “My tiles” on top; Standard with the switch off is what Reset did before.
  • Profiles – ready-made layouts for Start from and Based on: Standard (the built-in groups and tiles), All tiles (every tile and every page of the ▾ menus, by area, as a list in two columns), Developer (forms, code and reports · debugging and data tools · integration – in three tabs, with favourites), Minimal (six tiles as a list: forms, procedures, reports, users, log, settings), Getting started (tutorial, setup wizard, sample data, settings, branding, security check, users, forms), Users & security (accounts, rights, sessions, audit trail, log, notifications, security check), Operations (status, update, mail test · settings, nuconfig.php, branding · database, file manager, log, sessions, e-mail log), Reporting (reports, SQL builder, dashboards, database, import), Integration & mail (API clients and playground, compatibility, e-mail pages, notifications, prompt generator) and Blank (an empty page for your own tiles). Tiles a profile does not show are hidden – the search and Ctrl+K still find them. Pages a profile shows (e.g. New form) are pinned pages. Tiles this installation does not have (no Notes form, SQL Server without database tools, developer mode off) are left out, empty groups disappear; new tiles of later versions appear in the last group.
  • Order: drag a tile within its group, into another group or into Hidden – with the mouse, or on touch screens hold the tile for a moment, then drag (a quick swipe still scrolls). The arrows on a tile move it left / right. Groups are dragged by their handle () or moved with the arrows; type the group name right in place; the bin deletes a group (its tiles go to Hidden).
  • Hide: the eye on a tile (or drag it into Hidden); the eye in Hidden shows it again. New tiles of later versions appear in the last group.
  • Display: groups one below the other or as Tabs (the last tab is remembered in the browser); tiles large with description, compact, as a list or as a wide list.
  • Tabs with several groups: with display Tabs, + after the tabs creates a tab; the open tab is renamed in place, moved with its arrows or by dragging, and deleted with × (its groups move to the first tab). Drag a tile or a group over a tab title to open that tab and drop it there. Each group gets a tab selection; Add group next to a tab adds a group there. Without tabs every group is a tab of its own; a tab without tiles is not shown.
  • Own tiles (Add tile): label, description, icon (any Bootstrap Icons name bi-…, suggestions offered) and colour; it opens a form (its list, a new record with -1 or a record id), a nuBuilder Next page, a procedure (output in a new tab or hidden with a message only) or a link (https://… or index.php?…), optionally in a new tab. The pencil edits it, the bin deletes it.
  • Back to the default: Start from → Standard (replaces Reset). Changes are logged (Start page changed / reset). Stored in zzzzsys_nunext_setting.
  • $nuConfigGlobeadminHome (nuBuilder Forte's setting, also in the settings table): the id or code of a launch form opens that form instead of this page (nuhome or empty = this page). The tile page is then in the user menu under Start page (tiles).
