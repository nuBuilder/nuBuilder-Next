Overview

What nuBuilder Next is, how it relates to nuBuilder 4.9, and how this documentation is organised.

For: Everyone

nuBuilder Next is a modern front end for nuBuilder applications. It runs on the same database as nuBuilder 4.9 – the same forms, users, access levels, procedures, reports and data – so an application can be used in nuBuilder and in nuBuilder Next side by side, and a change made in one is seen in the other.

Like nuBuilder, nuBuilder Next is metadata-driven: a form is not a file of code but rows in nuBuilder's system tables (zzzzsys_form, zzzzsys_object …). nuBuilder Next reads these rows and draws lists and edit forms from them with Bootstrap 5, in light and dark mode and on phones. Custom JavaScript and PHP written for nuBuilder keep working through a compatibility layer of nuBuilder's functions.
