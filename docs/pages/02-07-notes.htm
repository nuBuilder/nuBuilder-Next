Notes

Formatted notes in categories.

For: Users with rights on: nunotes

Menu Notes: notes with formatted text (bold, lists, tables, links), grouped in categories. The list has a category filter next to the search (All, ∅ = without category, or one category); it can be switched off in the form builder (browse column option Filter). Updated on is set automatically on every save. Categories are managed with the Categories button above the notes list (form nunotescategroy); a missing category can also be added right in a note: open the category lookup and click Add – after saving it is chosen in the note. With the right to delete notes, each row of the list starts with a button: it asks once and deletes the note without opening it (the list stays where it is).
