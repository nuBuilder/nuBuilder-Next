Hash variables and the label menu

#…# variables in SQL, PHP and HTML, and the globeadmin's label menu.

For: Administrators (globeadmin, admin roles)

In the edit form, a right-click on the label of an object – on a content box title, on a button (input or run button), or on a title an HTML object draws itself (an element with class title, h1–h6, legend or card-header inside it, e.g. a framed box from your CSS) – opens a menu, as in nuBuilder Forte 4.x (a left click on a label focuses its field as usual; Ctrl + right-click shows the browser's own menu; the context-menu key or Shift+F10 also opens it; on phones and tablets a long press, where the browser supports it): Object: id (click copies the id), Properties… (opens the object in design mode), Rename…, Actions (Delete, Move to tab), Access, Align and Validation. The current value is marked; a change is saved at once and the form reloads. Not on nuBuilder Forte (4.x) system forms – except User Home (nuuserhome), whose objects the design mode edits too. On narrow screens a submenu that has no room beside the menu unfolds below its row (tap to open / close).

Hash variables (hash cookies)

Before SQL (browse, display, select, lookups), PHP (hooks, procedures) and HTML objects run, every #NAME# with a known name is replaced. Unknown names stay as they are (as in nuBuilder Forte), so LOCATE('#', '#x#') tests still work. JavaScript is not replaced – use nuGetProperty('name') there.

Procedures#PROCEDURE_CODE#procedures
  • Order: system and user variables win, then record fields, then properties, then hash cookies – a field called USER_ID or a property can never replace #USER_ID#.
  • Escaping (difference to nuBuilder Forte): values are escaped for where they go – quotes in SQL, quotes and $ in PHP strings, HTML entities in HTML. A value can't break out of '#field#'. Write hashes inside quotes in SQL and PHP.
  • #DEV_MODE# is 1 for the globeadmin when $nuConfigDevMode = true is set (also nuDevMode() in JavaScript).
  • #USER_PERMISSIONS# lists the active permission items of the user (nuBuilder Forte's zzzzsys_user_permission), separated by ", " – how to check one in SQL: Permission items in SQL.
  • Code editor: the # button in SQL, PHP and HTML editors (design mode and double-click editor) lists every variable with a description, the fields of the form and your hash cookies – click or Enter inserts it at the cursor.
  • Hash viewer: in a form, the globeadmin sees every variable with its current value and source.
