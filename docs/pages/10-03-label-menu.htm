Hash variables and the label menu

#…# variables in SQL, PHP and HTML, and the globeadmin's label menu.

For: Administrators (globeadmin, admin roles)

In the edit form, a right-click on the label of an object – on a word, an image, a content box title, on a button (input or run button), or on a title an HTML object draws itself (an element with class title, h1–h6, legend or card-header inside it, e.g. a framed box from your CSS) – opens a menu, as in nuBuilder Forte 4.x (a left click on a label focuses its field as usual; Ctrl + right-click shows the browser's own menu; the context-menu key or Shift+F10 also opens it; on phones and tablets a long press, where the browser supports it): Object: id (click copies the id), Properties… (opens the object in design mode), Rename…, Actions (Clone – a copy with the id <id>_2, its events and code, placed below the original –, Delete, Move to tab), Access, Align and Validation. The current value is marked; a change is saved at once and the form reloads. In the absolute layout the menu ends with Top, Left, Width and Height: the object moves and resizes while you type or use the arrows, and the new values are saved – without a reload – on Enter, when you leave the field or close the menu, and for the spin arrows when you release the mouse button. In a list (browse form), a right-click on a column title opens the column's menu – the same as in design mode: the title and id (click copies the id), Properties… (design mode with the column selected), Rename…, Align, Width (saved on Enter or when the menu closes), Filter, Move left / Move right, Hide and Delete; the list reloads after a change. Not on nuBuilder Forte (4.x) system forms – except User Home (nuuserhome), whose objects the design mode edits too. On narrow screens a submenu that has no room beside the menu unfolds below its row (tap to open / close).

On a button (run object or input button) the menu starts with Button settings…: one dialogue with the tabs Run (run objects only: what it runs – form, procedure, report, URL or a saved pivot –, the target, record ID and filter of a form, button or iframe, and where it opens; Open the target opens the chosen form, procedure or report), Events (the JavaScript of each event – add, change or delete), Label & look (label and icon) and Access. One Save stores everything and reloads the form; in a draft preview it goes into the draft. Alt + click on a button opens the same dialogue (not in design mode, where the panel shows these settings).

A right-click on a column title of a grid sub-form opens a short menu for that column, which is an object of the sub-form's own form: Object: id (click copies it), Properties… (that form in design mode with the column chosen, in a new tab) and Design the sub-form's form….

A right-click on a tab of the edit form opens the tab menu: Tab: title (click copies the tab id), Rename tab, Visibility (Visible, Hide tab, Hide for users), Move left / Move right, Delete tab (its objects move to the first remaining tab; not offered for the only tab) and Edit in design mode. Each change is saved at once and the form reloads; in design mode the tabs have the same menu of their own.

Hash variables (hash cookies)

Before SQL (browse, display, select, lookups), PHP (hooks, procedures) and HTML objects run, every #NAME# with a known name is replaced. Unknown names stay as they are (as in nuBuilder Forte), so LOCATE('#', '#x#') tests still work. JavaScript is not replaced – use nuGetProperty('name') there.

  • Field values in nuHash() are text, an empty (NULL) column is '' – as nuBuilder Forte. Forte also adds slashes before quotes (nuAddSlashes); nuBuilder Next does not.
  • Order: system and user variables win, then record fields, then properties, then hash cookies – a field called USER_ID or a property can never replace #USER_ID#.
  • Opening form: a form opened from an edit form (nuForm, a run button, a framed run object) also gets that record's fields as hash variables, after all the others – as nuBuilder Forte. A display of a new record can so use #year# of the record it was opened from. Opened from a list, nothing is passed on. In Before / After Save the empty fields of a new record are hash variables with an empty value.
  • Escaping (difference to nuBuilder Forte): values are escaped for where they go – quotes in SQL, quotes and $ in PHP strings, HTML entities in HTML. A value can't break out of '#field#'. Write hashes inside quotes in SQL and PHP.
  • Bound parameters ($nuDevSelectQueryRunParameterised = true; in nuconfig.php, a setting of nuBuilder Forte): the hash variables of the browse SQL and its columns, of select objects and of access conditions are passed to the database as bound parameters (?) instead of text. nuBuilder Forte does it for select objects and access conditions; nuBuilder Next also for browse lists. Rules:
    • '#PARENT_ID#' and #PARENT_ID# both become the parameter – write them as you like; the value can never become SQL.
    • Inside a longer string the value is put in as text (escaped) – LIKE '%#X#%' keeps working (it breaks in nuBuilder Forte); use LIKE CONCAT('%', #X#, '%') for a real parameter.
    • Where SQL needs a name the value is put in as text: #TABLE_ID#, after FROM / JOIN / INTO / UPDATE / TABLE, next to a .. Lists stay lists: IN (#ACCESS_LEVEL_IDS#). A list of your own in one hash variable (IN (#ids#) with 1,2,3) is one value when bound – use FIND_IN_SET or a sub-query.
    • A hash variable that has no value stays as it is ('#X#' is then the text #X#). Comments (--, /* */) are not touched.
    • Not affected: display SQL, lookups, reports, procedures (they use nuRunQuery($sql, [$params]) themselves), HTML and JavaScript.
  • #DEV_MODE# is 1 for the globeadmin when $nuConfigDevMode = true is set (also nuDevMode() in JavaScript).
  • #USER_PERMISSIONS# lists the active permission items of the user (nuBuilder Forte's zzzzsys_user_permission), separated by ", " – how to check one in SQL: Permission items in SQL.
  • Code editor: the # button in SQL, PHP and HTML editors (design mode and double-click editor) lists every variable with a description, the fields of the form and your hash cookies – click or Enter inserts it at the cursor.
  • Hash viewer: in a form, the globeadmin sees every variable with its current value and source.
