Hash variables and the label menu

#…# variables in SQL, PHP and HTML, and the globeadmin's label menu.

For: Administrators (globeadmin, admin roles)

In the edit form, a click on the label of an object opens a menu: Object: id (click copies the id), Properties… (opens the object in the form builder), Rename…, Actions (Delete, Move to tab), Access, Align and Validation. The current value is marked; a change is saved at once and the form reloads. Not on nuBuilder system forms. On narrow screens a submenu that has no room beside the menu unfolds below its row (tap to open / close).

Hash variables (hash cookies)

Before SQL (browse, display, select, lookups), PHP (hooks, procedures) and HTML objects run, every #NAME# with a known name is replaced. Unknown names stay as they are (as in nuBuilder), so LOCATE('#', '#x#') tests still work. JavaScript is not replaced – use nuGetProperty('name') there.

Procedures#PROCEDURE_CODE#procedures
  • Order: system and user variables win, then record fields, then properties, then hash cookies – a field called USER_ID or a property can never replace #USER_ID#.
  • Escaping (difference to nuBuilder): values are escaped for where they go – quotes in SQL, quotes and $ in PHP strings, HTML entities in HTML. A value can't break out of '#field#'. Write hashes inside quotes in SQL and PHP.
  • #DEV_MODE# is 1 for the globeadmin when $nuConfigDevMode = true is set (also nuDevMode() in JavaScript).
  • #USER_PERMISSIONS# lists the active permission items of the user (nuBuilder's zzzzsys_user_permission), comma separated.
  • Code editor: the # button in SQL, PHP and HTML editors (form builder and double-click editor) lists every variable with a description, the fields of the form and your hash cookies – click or Enter inserts it at the cursor.
  • Hash viewer: in a form, the globeadmin sees every variable with its current value and source.
