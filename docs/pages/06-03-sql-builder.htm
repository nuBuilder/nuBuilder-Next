SQL builder

Visual queries for reports.

For: Users with rights on: nuselect

Forms → Tools → SQL builder: queries for reports (nuBuilder Forte's zzzzsys_select). Add tables from the list (click or drag), tick the columns (or all), give a table an alias, drag a column onto a column of another table to join them – click the join to switch between JOIN and LEFT JOIN. Clauses add WHERE, GROUP BY, HAVING and ORDER BY; conditions may contain hash variables (= '#cus_country#'). The SQL is written as nuBuilder Forte's builder writes it; Edit SQL by hand (nuBuilder Forte's "Edit Manually") keeps your own SQL. Run shows the first 50 rows; it needs the right to change queries (Save or Add on nuselect), accepts one reading statement only (no INTO, locks or writes after a WITH) and runs it in a read-only transaction that is rolled back, with a time limit of 15 seconds. Error details (table and column names) are shown to the globeadmin only. A query that reports use cannot be deleted. The graphic is stored in nuBuilder Forte's format.
