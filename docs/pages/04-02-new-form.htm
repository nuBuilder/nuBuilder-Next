Creating a form

New forms from an existing or a new table, or written by an AI.

For: Users with rights on: nuform

  • Existing table: pick the table (type part of its name to search the list) and primary key – objects and list columns are generated from its columns.
  • New table: enter columns (name, label, type, length, required). The table gets a text primary key – nuBuilder ID (nuBuilder Forte's ids, VARCHAR(25)) or UUID (VARCHAR(36): new records get a UUID, easy to exchange with other systems; the column type Record ID – UUID is for columns that point to such records) and optionally audit columns (created/updated at/by), filled on every save, and/or nuBuilder Forte's record log <table>_nulog (see below). crosses a column out – it is not created; brings it back.

After creating (not for sub-forms):

  • Add a button to User Home (on by default): as nuBuilder Forte's Fast Form builder does, a run button for the new form is placed on the tab Fast Forms of nuBuilder Forte's launch form User Home (nuuserhome) – nuBuilder Forte shows the same button; a message after creating says so. User Home opens from the house icon next to ☆ in the start page's search row, the user menu and the start page tile User Home.
  • Access for access levels (with the right to change access levels): the levels you tick get all rights on the new form, and their users find it on their start page – on the automatic one at once, on a saved start page layout as a new tile in its first group.
  • Changing User Home: the form builder button (on the form, or Forms → User Home) opens it like other forms – tabs, objects with their events and the Before Edit PHP can be changed, also as a draft. nuBuilder Forte's updates keep exactly these parts; its form settings, other code and list stay read-only.
  • A database without User Home gets it on installation and with every update – nuBuilder Forte's launch form nuuserhome with its tabs Main and Fast Forms, as nuBuilder Forte's installation creates it. An existing User Home is never changed.
  • A user whose access level has User Home as its home form may open it and finds it on the automatic start page, as in nuBuilder Forte.

Forms with AI

A form can be created or changed with any AI chat (Claude, ChatGPT …) – no API key, nothing is sent from nuBuilder Next: Forms → With AI (also in the new-form page) for a new form, Change with AI in the form builder for an existing one.

  1. Describe it (fields, lists, lookups, the table – new or existing) choose the tables in the prompt (searchable, several; the form's own table is preselected – none chosen = all tables, up to 80) and click Copy prompt. The prompt holds a short description of nuBuilder Next's form format, the chosen tables with their columns, the forms lookups and sub-forms can use and – when changing – the current form. Paste it into the AI chat.
  2. Paste the AI's whole answer and click Check: errors (unknown types, forms or columns that do not exist, duplicate ids …) are listed – ask the AI to correct them or edit the JSON. Otherwise you see what happens: a new table, new columns, new / changed / removed objects, tab and list changes.
  3. Create draft: a missing table or columns are created first, only after you tick the box (they stay even if the draft is discarded). A new form is created with status Draft – only designers see it; check it with Open form and publish it in the builder. A change becomes a form draft: the live form stays as it is until you preview, compare and publish it.
  • The format describes inputs (all input types), textareas, selects (options or SQL), lookups, sub-forms (an existing form of type sub-form), display and HTML objects and words, tabs and the list columns. Other objects (calculations, run buttons, charts …) are marked “keep” and stay unchanged, as do events, custom code, hooks and the SQL builder rows.
  • Existing objects keep their place; new ones are placed below the object before them (or next to it with same_row) and move the following ones down.
  • Not for nuBuilder Forte's system forms and page forms. Since the prompt contains the table names and columns, check what your AI provider may receive.
