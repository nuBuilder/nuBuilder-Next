Themes

The look of buttons, fields, tabs, lists and forms – five built-in themes, own ones, per access level or chosen by the users.

For: Administrators (globeadmin, admin roles with the right Branding)

Admin tools → Themes (index.php?p=themes) sets the look of nuBuilder Next's own pages and of the forms of your application. A theme is a set of values; an empty value keeps nuBuilder Next's own look.

Built-in themes

  • nuBuilder Next – the normal look.
  • Forte Classic – close to nuBuilder Forte 4.9: Segoe UI 13 px, small corners, no shadows, light action buttons, tabs as boxes, Forte's blue form buttons.
  • Corporate – dark blue top bar, square corners, compact spacing, semi-bold buttons and labels.
  • Soft – rounded corners, light violet surfaces, more spacing, tabs as pills.
  • High contrast – black text and borders, 16 px Verdana, a yellow focus ring, strong list headers; a dark version with white on black.

Built-in themes cannot be changed: Duplicate makes an editable copy (also of an own theme).

Theme names are unique – also against the built-in themes, without regard to upper / lower case. The name field says so while you type and Save refuses a name in use; a copy or an imported theme whose name is taken gets a number, e.g. Ocean (2).

Editing a theme

The editor groups the values: General (accent colour, page background, cards and fields background, text, secondary text, borders, corner radius 0–16 px, shadow of cards), Font and spacing (font – system fonts only, since the Content Security Policy loads fonts only from this server –, size 12–16 px, density compact / comfortable), Top bar (background, text and icons – on a dark bar nuBuilder Next's logo switches to its light version), Buttons of the pages (Back / Save / Clone and toolbar buttons, nuBuilder Forte's nuActionButton), Fields and labels (background, text, border, focus colour, labels and their weight, the required mark), Tabs (style: underline, boxes as in nuBuilder Forte, or pills; colours), Lists (header, row under the mouse, stripes) and Forms (background and text of form buttons – without a text colour it is white or black, whichever is readable –, labels of form fields).

Every colour has a value for light and one for dark mode; an empty dark colour keeps nuBuilder Next's dark colour, so the dark mode switch works with every theme. The preview on the right changes while you type and switches between light and dark; below it, pairs that are hard to read (e.g. button text on its background) are named with their contrast ratio. Changes apply to everyone after Save.

Themes can be moved to another installation: ⋯ → Export saves a JSON file, Import creates a new own theme from it. The file holds every colour, light and dark – also those the theme leaves to nuBuilder Next (so the built-in nuBuilder Next theme exports its own colours) – and the other values (corners, font, density …) the theme sets.

Who uses which theme

  • Theme for everyone (also Use for everyone on a theme) – also on the sign-in pages.
  • Per access level – users of the level get this theme instead (their main access level). The list is folded at first – a click on its title opens it; the badge counts the levels with a theme of their own.
  • Users may choose their theme – the ticked themes (none ticked = all) appear in the menu with light / dark mode; As set for me goes back. A user's choice wins over the theme of the access level. The globeadmin's choice is kept in the settings, demo visitors' in the session.
  • Use for me on a theme (also in the light / dark menu) – only for you. The globeadmin can always choose any theme, also when users may not choose; others get the button when users may choose and the theme is allowed. The badge Yours marks the theme you see; ⋯ → Stop using for me goes back.

A theme in use (for everyone or an access level) cannot be deleted. The theme is a small generated stylesheet the browser caches until the theme changes. It is loaded before Global code CSS, so your own CSS – Global code, Setup → Style, a form's Style – still wins; nuBuilder Forte (4.x) itself is not affected. The accent colour of earlier versions (Branding) became the own theme "My theme".
