Customization

Your own pages, start page hooks, look and feel, and the libraries you can rely on.

For: Users with rights on: nuform

Ways to extend nuBuilder Next beyond forms, from the smallest to the largest:

  • Global code – JavaScript, CSS and includes for every form, and Global JS & CSS with a page hook for every page (Global code), and $nuConfigIncludeJS / $nuConfigIncludeCSS / $nuConfigIncludePHP in nuconfig.php.
  • Start page hooks – change tiles, badges and texts of start pages with the procedures nu_home / nu_home_user.
  • Theming – CSS variables, light and dark mode, branding.
  • Pages – complete PHP apps of your own that run inside nuBuilder Next with its login and rights.
