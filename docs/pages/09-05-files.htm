Files

Images and documents stored in the database.

For: Users with rights on: nufile

Forms → Tools → Files: small images and documents kept in the database (nuBuilder Forte's table zzzzsys_file). Image objects show them, reports and custom code use them by their code (e.g. Image:logo).

  • Code is required and unique. Description and group help to find files; the list can be filtered by group.
  • Choose a file, drag it onto the drop zone or paste an image with Ctrl+V. A new file proposes its name as code. The maximum size is set by the administrator (default 300 KB).
  • The preview shows images; every file can be downloaded. Used by lists the image objects showing the file – such a file cannot be deleted.
  • Files of nuBuilder Forte (4.x) itself (System) can only be changed by the globeadmin.

See also: File Manager (nuFiles)
