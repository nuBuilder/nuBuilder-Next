Authentication and security

How rights work, how users sign in, and how the installation is protected.

For: Users with rights on: nuaccess, nupermissionitem

The globeadmin may do everything. All other users get their rights from their access level (zzzzsys_access_form), exactly like in nuBuilder Forte (4.x). nuBuilder Next's own screens are protected by nuBuilder Forte's system forms:

Row present = view; Save = edit; Add/New = create; Delete; Clone; Print = print view and CSV export. Procedures need a row in zzzzsys_access_php (or global).

Admin-equivalent rights (marked on the access level page): Save, Add, New, Delete or Clone on nuform, nuprocedure, nuselect, nusetup, nuuser or nuaccess give full control – PHP code on the server, SQL on every table, the mail server (password-reset mails), the passwords and access levels of all users. With Only the globeadmin grants admin rights (Security check, on by default):

  • only the globeadmin adds these rights to an access level or assigns an access level that has them (also through the REST API);
  • nobody else changes, archives, deletes or resets a user whose access level has them;
  • nobody changes his own access level or the rights of his own access level;
  • nuBuilder Forte's system forms on users, rights, code and setup (zzzzsys_user, zzzzsys_access*, zzzzsys_php, zzzzsys_form, zzzzsys_object …) are saved through the form runtime by the globeadmin only.
