Your password and two-step login

Changing your password and setting up a second factor.

For: Everyone

Open the Security tile of the start page (users without an admin role: the user menu).

Changing your password

Enter your current password and the new one twice. The minimum length is set by your administrator. Forgot it? Use Forgot password on the login page – you receive a link by e-mail that is valid for 60 minutes and can be used once.

Two-step login (2FA)

  • Authenticator app (Microsoft / Google Authenticator, …): scan the QR code and confirm with a code. From then on you enter the 6-digit code of the app after your password.
  • Code by e-mail: if no app is set up, a 6-digit code is sent to your e-mail address.
  • Remember this device: no code is asked on this browser for a number of days.
  • Lost your phone? Ask your administrator to reset your two-step login.
