Code search

Find where something is used in the code of the application – a function, a table, a column, a hash variable – across forms, procedures, SQL and templates at once, and replace it where you tick it.

For: Developers (globeadmin, admin roles with the right Code search)

Open it from the start page tile Code search (index.php?p=codesearch, page number 296), from a form's ⋮ menu → Find in this form's code, or from the function reference: the next to a function searches for its calls. The search only reads – nothing typed here is run, and nothing is changed unless you use Replace.

What is searched

  • Procedures – PHP and JavaScript.
  • Forms – JavaScript, Browse JS, Edit JS, CSS, Browse SQL, the SQL of list columns, validation rules and the form events (Before Browse, Before Edit, Before Save, After Save, Before Delete, After Delete).
  • Objects – event JavaScript (onclick, onchange …), lookup JavaScript and PHP with their After Browse PHP, HTML code and its JavaScript, input JavaScript, the options and display SQL of selects and displays, calc formulas, access conditions, run filters and styles.
  • SQL builder queries – also those reports run on.
  • Global code – header, style and include of the form pages, Global JavaScript and CSS.
  • Code snippets and e-mail templates (subject and body).
  • Dashboard widget SQL, data export SQL, webhook templates and the default values of custom user fields.
  • The files of custom pages (PHP, JavaScript, CSS, HTML, SQL, JSON … up to 1 MB each) and the open drafts of forms – marked draft.

nuBuilder Forte's own forms, procedures and templates (ids starting with nu or nx_) are left out unless you switch them on under Filters.

Searching

  • Exact text finds the text as typed. All words finds the parts that contain all of the words, Any word those with at least one; "words in quotes" stay together.
  • Whole word does not match inside a longer name (nuGetValue does not find nuGetValues). Match case and Regular expression work as in a code editor.
  • Without leaves out every part that contains that text.
  • Filters: language, where (procedures, form events, object SQL …), forms, form group, department, team and project.
  • Where is … used? fills the search with a documented function, a table or a hash variable. Functions nuBuilder Next lacks finds calls of nuBuilder Forte functions that are listed under Not ported.

Results

The hits are grouped by form, procedure, query or template, each part with its lines and two lines around them. A click on a line number opens the editor at that line – design mode's Code, the procedure, the SQL builder, Global code; parts without a code editor (object properties, list columns, rules) open at their place in design mode. Open opens the whole form or item.

Export writes the hits as CSV or Excel. My searches keeps searches you use again; they belong to you. At most 2,000 hits are shown – narrow the search when the list says so.

Search and replace

For the globeadmin: Replace… opens a field for the new text, Preview shows every hit with the line as it will read afterwards (password confirmed first). Untick the lines that should stay, then Replace in … ticked lines.

  • Replace needs Exact text or a Regular expression; in a regular expression $1, $2 … insert its groups. Whole word and Match case apply.
  • Only the ticked lines change; the other hits of the same part stay. A part that changed since the preview is left alone (search again), and PHP that would no longer be valid afterwards is not written.
  • Not replaced here: forms with an open draft (change them in design mode or publish first), drafts, files of custom pages, data export queries, validation rules, SQL builder queries and nuBuilder Forte's own code – the preview says why next to such a part.
  • Every form that changes gets a version in its history first (design mode → History). Recent replacements lists the last runs; Undo puts each part back while it still holds what the run wrote.
