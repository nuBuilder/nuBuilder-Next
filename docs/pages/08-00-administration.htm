Administration

Users, configuration, settings, start pages and the admin tools.

For: Users with rights on: nuuser

Administration is done by the globeadmin and by users with an admin role. Almost everything is reached from the tiles of the start page (groups Users & rights, Development, Communication, System, Look, Data, Integration) or from Admin tools in the user menu.

A typical order for a new installation: install → security check → e-mail → access levels → users → start pages.

Shortcuts for administrators

On every form page (Ctrl+Shift+key, most also in the ⋮ options menu): A arrange objects, H add object, F form properties, O object list (A, F and O only as shortcuts; all open design mode in a new tab – H with Add, O with Structure; rights on nuform, not for nuBuilder Forte's own forms), D nuDebug results, E phpMyAdmin, Q Tiny File Manager, J logged-in users, M form info (opens the (i) panel; only as a shortcut), V version info, X the hash variables of the form. Inspect record is in the menu without a shortcut (Ctrl+Shift+I opens the browser's developer tools). The Cloner is on the Forms page, the App cloner and the Prompt generator on Admin tools; nuBuilder Forte's Backup and Setup do not exist in nuBuilder Next.
