Theming and CSS

Light and dark mode, CSS variables and where your own CSS goes.

For: Administrators (globeadmin, admin roles)

nuBuilder Next is built on Bootstrap 5 with a thin layer of its own CSS. Light and dark mode use Bootstrap's colour modes: the theme (light, dark, automatic) is chosen in the menu bar and set as data-bs-theme on <html>. Style your own elements with Bootstrap's CSS variables (var(--bs-body-color), var(--bs-border-color) …) and they follow the theme automatically.

nuBuilder Next's CSS variables

VariableUsed for
--nu-accent, --nu-accent-2Accent colours (logo, highlights, form buttons) – set by Branding
--nu-on-accentText on the accent colour (white, black on a very light accent) – set by Branding
--nu-pagePage background
--nu-surfaceBackground of cards, the menu bar and panels
--nu-highlightHighlighted search words in lists

Override them for dark mode under [data-bs-theme="dark"]. Other --nu-… variables in assets/css/ are internal and may change.

Where your CSS goes

  • All forms: Setup → Style (Global code) or $nuConfigIncludeCSS – loaded after nuBuilder Next's styles, so they can override them.
  • All pages: Global CSS (Global code → All pages) – target single pages with body[data-nu-page="…"].
  • One form: the form's style in the form builder.
  • Pages: their own CSS files in the page folder – nuBuilder Next adds nothing (Pages).

Do not edit the files in assets/css/: an update replaces them. The element ids of forms are nuBuilder Forte's (see Form rendering pipeline), so CSS written for nuBuilder Forte (4.x) mostly applies; forms with the automatic or grid layout use Bootstrap rows and columns instead of pixel positions.
