Function reference

Every PHP and JavaScript function with signature, description and example.

For: Administrators (globeadmin, admin roles)

Every function for your own code, in two tabs. PHP: procedures, form hooks (Before Edit, Before Save …), lookups and page forms. JavaScript: a form's custom code (Custom code → JavaScript, Setup → Header), the hooks a form may define, the page form SDK (NuPage) and the start page (nuHome). Each function shows its parameters, return value, description, an example call and – when it returns something – a sample result. nuBuilder = works as in nuBuilder 4.9 (a form or procedure using it keeps working in nuBuilder), nuBuilder Next = only in nuBuilder Next, with the version that added it. Overviews: PHP functions, JavaScript functions, Hash variables.
