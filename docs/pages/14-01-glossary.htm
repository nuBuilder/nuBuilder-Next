Glossary

The terms used in nuBuilder Forte (4.x) and nuBuilder Next.

For: Everyone

Access level
The set of forms (with their buttons), procedures and reports a user may use. Every user except the globeadmin has one. Access levels
Action buttons
The buttons of a record or list: Save, Add, Clone, Delete, Print – each one a right of the access level. Access levels
Admin role
A part of the globeadmin's rights given to a user, per tool view or change. nuBuilder Next only. Admin roles
App cloner
Copies the whole application into another database or an SQL file. App cloner
Audit trail
Every change of a record, one row per column, with history and restore. Audit trail
Breadcrumbs
The path above a form (start page › list › record); Back goes one step up.
Browse
The list of a form (nuBuilder Forte's name). Its rows come from the form's browse SQL, its columns are the browse columns.
Column
One piece of information in a table (also field); an object of a form saves into the column with the same name as its ID. Database basics
Criteria form
The form a report opens first (its launch form): the user fills in the values the report uses, such as a date range. A report step by step
Dashboard
A set of widgets (KPI tile, chart, table) built from SQL, shown on start pages or forms. Dashboards
Data export
A saved export of tables, views or queries to Excel or CSV, run from its page or the REST API. Data export
Data import
Loads a CSV file (or, with the PhpSpreadsheet pack, an Excel / OpenDocument sheet) into a table: mapping, a trial run, then the import. Data import
Draft
A working copy of a form; users keep the live form until the draft is published. Drafts and publishing
Edit screen
nuBuilder Forte's name for the record view of a form – the fields of one record with the action buttons.
Field data access
Server-side rules per field: shown, masked, read only or withheld for certain users. Data access
Foreign key
A column that holds the primary key of a row in another table (con_organization_id) and so links the two – the basis of lookups and sub-forms. Database basics
Form
A list and / or edit screen defined by rows in zzzzsys_form and related tables. Types: browse and edit, browse, edit, launch, subform, page.
Format
A date, number or text-mask format shared with nuBuilder Forte (zzzzsys_format). Formats
Global code
JavaScript and CSS of Settings → Code & includes → Global code: nuBuilder Forte's Setup Header, Style and Include for form pages, and Global JS & CSS for every page. Global code
Global hook
A procedure with a reserved code (nu_before_save, nu_before_edit, nu_startup …) that runs for every form or every login. Hooks
Globeadmin
The administrator account defined in nuconfig.php; may do everything.
Hash variable
#NAME# placeholder replaced by its value in SQL, PHP and HTML – the user, the record, fields, properties. Also "hash cookie". Hash variables
Hook
PHP of a form that runs at a fixed moment: Before Browse, Before Edit, Before Save, After Save, Before Delete, After Delete; After Browse of a lookup. Form lifecycle
IP access
Rules which addresses may sign in, per access level. IP access
Item
An entry of nuBuilder Forte's item lists (zzzzsys_item), e.g. for selects. Items
Launch form
A form without a table – a menu or a page of buttons and HTML.
Library pack
A signed zip that installs a third-party library (TinyMCE, phpMyAdmin …) into vendor/packs/. Library packs
List view
The layout of one of nuBuilder Next's own lists: columns, sort, phone view. List views
Lookup
An object that stores the primary key of a record of another form and shows its code and description. Object types
Notification
A message to users shown by the bell in the top bar, optionally with a read receipt or an e-mail. Notifications
Object
A field or element on a form (input, select, lookup, subform, calc, HTML, run …); its id is the column it saves to.
Page (form type)
A PHP app of your own in custom/pages/ that runs inside nuBuilder Next. Pages
Parent and child record
In a one-to-many relationship the parent (an invoice) has many children (its items), linked by the foreign key in the child rows. Database basics
Password policy
Rules for new passwords (length, characters, leaked-password check) and how often they must be changed. Password policy
Permission item
A named switch that code checks with nuUserHasPermission(). Permission items
Primary key
The column whose value is unique in every row of a table; filled by nuBuilder Next when a record is created, never shown to users. Database basics
Procedure
Named PHP in zzzzsys_php, started by buttons, run objects, nuRunPHP() or reports. Procedures
Property
A value set with nuSetProperty() that is available as a hash variable to the form and the forms opened from it.
Record
One row of a table – one customer, one invoice.
Record ID
The primary key of the open record; -1 for a new one (#RECORD_ID#).
Run object
A button object that opens a form, report or procedure. Run objects
Search screen
nuBuilder Forte's name for a form's list (also browse screen). Lists
Settings centre
All settings of the installation in one place: sections in a side bar, a search over every setting. Settings
Subform
A form shown as rows inside another form, linked by a foreign key.
Theme
A set of colours (light and dark) for the whole interface, chosen per installation, access level or user. Themes
Tile
An entry of a start page: a form, report, procedure, page or link.
Webhook
An HTTPS call nuBuilder Next makes to another system when a record of a form is saved or deleted. Webhooks
zzzzsys_ tables
nuBuilder Forte's system tables; zzzzsys_nunext_ are nuBuilder Next's own. Table reference
