Access levels

Which forms and buttons a user may use.

For: Users with rights on: nuaccess

Menu Access levels. An access level lists the forms a user may open and, per form, the buttons: Save, Add/New, Delete, Clone, Print. The row itself means "may view". Procedures need their own entry.

The form has two tabs: General (code, description, group, start form, two-factor login, the users with this level) and Form rights (the forms and their buttons; the badge shows how many). The open tab stays after Save and in the address (&tab=rights); an error opens the tab that shows it.

  • Use two-factor authentication: users of this level must confirm their login with a second factor – an authenticator app or a code by e-mail (hover or focus the icon for this hint). It needs $nuConfig2FAUser = true; the form shows whether it is on, and while it is off the globeadmin can switch it on there (Switch on, or a link to Settings when the settings table is used).
  • Reports: the reports users of this level may run (nuBuilder's zzzzsys_access_report); the form shows how many are ticked. They are set on the report itself (see Reports).
  • Adding forms: pick one form from the list (type to search by code or description; forms already in the list are greyed out), or click Several…: search (code, description, table), filter by form group, type and own / nuBuilder system forms, tick the forms (or Select all shown) and choose the rights the new rows get – e.g. everything but Delete. Forms already in the list are hidden. Save afterwards.
  • Removing a form: crosses the row out – it is removed when you save the access level. Until then the same button () brings it back. The form builder's lists (tabs, list columns, events, columns of a new table, HTML attributes) work the same way.
  • Data mode and Form type per form (as in nuBuilder 4.9, enforced): No changes to existing records opens existing records read only, without Save – the server refuses a save even from code (“Changes to existing records are not allowed”); new records, Clone and Delete follow their own rights. Browse only shows the list, but no record (also no new one: no Add, rows open nothing); Edit only opens records, but not the list (nor its export). The globeadmin and admin roles with change on the form are not limited.
  • An access level cannot be deleted while users still have it. Deleting it also removes its form, procedure and report rights; cloning copies them.
