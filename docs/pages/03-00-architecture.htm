Architecture

How a request travels through nuBuilder Next – for developers who extend or debug it.

For: Administrators (globeadmin, admin roles)

nuBuilder Next is a plain PHP application (PHP 8.1+) without a framework: one front controller, server-rendered pages, and small JSON endpoints that the page scripts call. It uses jQuery and Bootstrap 5 in the browser, and runs nuBuilder's form code through a compatibility layer.

Folders

Folder / fileContents
index.phpFront controller: boot, route table, access checks, then pages/nu<route>.php
api.php, cron.php, oauth.php, dbadmin.phpOther entry points: REST API, command line, OAuth return address, Adminer
pages/One file per route – the page or JSON endpoint
core/Classes and functions (loaded on first use by core/nuapp.php)
core/form/The form runtime: metadata, rendering, lists, saving, hooks, hash variables, drafts
assets/nuBuilder Next's CSS and JavaScript (assets/js/nu/ = form runtime)
vendor/bundled/, vendor/packs/Bundled third-party libraries; installed library packs
apps/, custom/pages/Built-in pages (nuFiles); your own pages
install/Schema scripts, expected schema, default settings, database steps of updates
lang/, docs/Interface texts; this documentation
