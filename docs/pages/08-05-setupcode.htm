Setup code

Advanced Header JavaScript, style and include of nuBuilder's Setup form.

For: Administrators (globeadmin, admin roles)

Admin tools → Setup code (globeadmin or the admin role right Setup code – a full-access right, because the code runs for every user) edits the three code fields of nuBuilder's Setup form in zzzzsys_setup, so nuBuilder and nuBuilder Next stay in step. Each field has its own tab and code editor; the tab is part of the address (#header, #style, #include) and stays open after Save.

  • Header (JavaScript) – set_header: on every form page after nuBuilder Next's runtime and before the form's own code – your global functions and nuBuilder's nuLoadEditGlobal, nuLoadBrowseGlobal, nuOnLoad.
  • Style (CSS) – set_style: on every form page after nuBuilder Next's styles.
  • Include (HTML) – set_include: its <link>, <script> and <style> elements are added to every form page (after the runtime and $nuConfigIncludeJS, before Header); other text, HTML comments and /* … */ blocks – such as nuBuilder's default text – are ignored. Addresses on other servers are allowed by the page's Content-Security-Policy. (nuBuilder 4.9 saves this field, but in our tests did not output it.)
  • Only changed fields are written. A field someone else changed since the page was opened (in nuBuilder or another tab) is not overwritten: the page says which one and keeps your text – saving again overwrites. Saves are logged (Setup code changed, with the fields).
