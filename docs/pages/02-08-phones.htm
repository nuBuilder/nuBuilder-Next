Phones and small screens

How nuBuilder Next adapts to phones and tablets, in one place.

For: Everyone

nuBuilder Next has no separate mobile version: every page adapts to the width of the screen. The main differences:

WhereOn a phone
Menu barWithout a logo (Branding): the icons stay in the bar, the areas move into the user menu (☰). With a logo: the areas are behind the ☰ button, and the pin button next to it keeps the menu open on every page (until it is tapped again; kept per browser). The user button shows only its icon.
Record buttonsSave, Clone and Delete show only their icon (Save as a floppy disk); the text is the tooltip.
Tabs with several cardsSuch a tab shows a small ▾. A tap on it – or a long tap on the tab (e.g. General of the user form) – lists its sections – Person, Login credentials, Access & roles …; a tap jumps to that card. On a computer: right-click on the tab.
Start pageA layout without its own phone settings shows a one-column list, and tabs become the side bar. A layout can have separate settings for phone (narrower than 576 px), tablet (narrower than 992 px) and desktop – see Start page of the globeadmin.
Lists of nuBuilder NextBelow 768 px every row is a card (title, badge, up to four lines), or a compact table whose first column stays while the others scroll – set per list in its list view. A button next to the view menu switches between cards and table on your phone; the choice is kept on the device.
Form listsBelow 576 px every row is a card: the first column as its title, the others as Title: value lines. No page-size choice (Back / Next stay). A list shown inside another form (a run object) gets a compact header, keeps its filters folded behind the funnel and grows to its rows.
Edit formsEvery form puts its objects below each other – also forms with fixed positions (nuBuilder Forte's pixel layout): below 576 px each field gets its label above it and the full width, in the order of their positions (top, then left); content boxes become section titles. Form code can keep the fixed layout with nuNextPhoneLayout(false) in nuOnLoad.
DashboardsOne widget per row (tablets: two); table widgets show each row as a block (first column as title).
Admin rolesEach right is a row with its name and the choices None · View · Change as buttons.
Help icons and tooltipsTap instead of pointing.

On wider screens forms built with absolute positions keep their positions; the automatic and grid layouts turn the same objects into responsive rows (see Form rendering pipeline).
