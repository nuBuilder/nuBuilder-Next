Phones and small screens

How nuBuilder Next adapts to phones and tablets, in one place.

For: Everyone

nuBuilder Next has no separate mobile version: every page adapts to the width of the screen. The main differences:

WhereOn a phone
Menu barBehind the ☰ button.
Start pageA layout without its own phone settings shows a one-column list, and tabs become the side bar. A layout can have separate settings for phone (narrower than 576 px), tablet (narrower than 992 px) and desktop – see Start page of the globeadmin.
Lists of nuBuilder NextBelow 768 px every row is a card (title, badge, up to four lines), or a compact table whose first column stays while the others scroll – set per list in its list view. A button next to the view menu switches between cards and table on your phone; the choice is kept on the device.
Form listsNo page-size choice (Back / Next stay).
Edit formsForms with automatic or grid layout put objects below each other; Save, Clone and Delete show only their icon (the text is the tooltip).
DashboardsOne widget per row (tablets: two).
Help icons and tooltipsTap instead of pointing.

Forms built with absolute positions (nuBuilder Forte's pixel layout) keep their positions; the automatic and grid layouts turn the same objects into responsive rows (see Form rendering pipeline).
