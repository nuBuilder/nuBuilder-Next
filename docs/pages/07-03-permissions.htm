Permission items

Named switches your own code checks.

For: Users with rights on: nupermissionitem

Start page tile Permission items, or Manage at the permission items of the user form (rights of nuBuilder Forte's form nupermissionitem). A permission item is a named switch that your own code checks – for things an access level cannot express, e.g. "may approve invoices" for some users of the same access level.

  • Ident: the name used in code, unique (letters, digits and _ . : -). Group sorts the items in lists and in the user form.
  • Users: add or remove users directly on the item, or tick the item in the user form – both edit the same assignment (zzzzsys_user_permission, as nuBuilder Forte (4.x)). Below, the saved users of the item with a search and Active / Archived / All, each opening the user in a new tab, and Show in the users list (also a new tab); in the list of items the Users count opens the users list filtered by the item.
  • Used in code lists form code, events and procedures that name the ident in quotes.
  • Usage in code (folded below the description, a click opens it): how to check this item – nuUserHasPermission() in PHP / JavaScript, and in SQL with #USER_PERMISSIONS# or a sub-query (see Permission items in SQL).
  • Deleting an item removes it from all users. The globeadmin has every item.

Checking an item: PHP nuUserHasPermission('ident') or nuGetUserPermissions(), JavaScript nuUserHasPermission('ident') or nuUserPermissions(), SQL / code #USER_PERMISSIONS# (see Permission items in SQL). Check on the server too (Before Save) – a browser check alone can be bypassed.

Permission items in SQL

Browse SQL, lookups, report and select SQL and access conditions can check an item – the same way as in nuBuilder Forte. #USER_PERMISSIONS# holds the active items of the user, sorted and separated by ", " (e.g. CAN_EXPORT, SEE_PRICES). Keep hash variables inside quotes.

  • With #USER_PERMISSIONS# (MySQL and SQL Server, shown on the permission item's page): commas around the list, so the first and the last item are found too. 
    WHERE ', #USER_PERMISSIONS#,' LIKE '%, SEE_PRICES,%'
  • With #USER_PERMISSIONS# with FIND_IN_SET (MySQL / MariaDB only): REPLACE removes the spaces, otherwise every item after the first is not found. 
    WHERE FIND_IN_SET('SEE_PRICES', REPLACE('#USER_PERMISSIONS#', ', ', ',')) > 0
  • With the permission tables (MySQL and SQL Server): 
    WHERE EXISTS (
    SELECT 1
    FROM zzzzsys_user_permission up
    JOIN zzzzsys_permission_item pi ON pi.zzzzsys_permission_item_id = up.upe_ident
    WHERE up.upe_zzzzsys_user_id = '#USER_ID#'
      AND up.upe_active = '1'
      AND pi.pme_ident = 'SEE_PRICES'
)
  • The globeadmin has no items in the tables and an empty #USER_PERMISSIONS# (as in nuBuilder Forte) – add OR '#GLOBAL_ACCESS#' = '1' to let the globeadmin through.
  • A column only for some users: 
    CASE WHEN FIND_IN_SET('SEE_PRICES', REPLACE('#USER_PERMISSIONS#', ', ', ',')) > 0 THEN price ELSE NULL END AS price
