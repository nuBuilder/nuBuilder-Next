Inspect record

Advanced Every column of a record as stored in the database.

For: Administrators (globeadmin, admin roles)

In an edit form, options menu ⋮ → Inspect record (globeadmin, saved records) opens the record in a new tab: every column of the table with its data type and the value stored in the database – also columns that are not on the form.

  • Sort by clicking a column title (#, column, type, value); show all columns, only those with a value or only empty / NULL ones; search in names, types and values.
  • Keys: primary key, real foreign keys, unique and normal indexes; nuBuilder-style references (…_zzzzsys_access_id) are marked as probable links. The tooltip of the type shows NULL / NOT NULL, default and comment.
  • NULL and an empty text are shown differently; long values are cut to one line – click to see all (JSON formatted). Values of password / token columns are blurred until you click the eye (demo users only see dots). Copy a value or the whole record as JSON. Read only.
