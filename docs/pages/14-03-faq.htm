FAQ

Short answers to frequent questions.

For: Everyone

Can nuBuilder and nuBuilder Next run on the same database at the same time?
Yes. They share forms, users, rights and data; nuBuilder Next keeps its own extras in zzzzsys_nunext_* tables that nuBuilder ignores. See nuBuilder and nuBuilder Next.
Does my nuBuilder JavaScript and PHP still work?
Mostly – nuBuilder's functions are implemented for form code, hooks and procedures. The Compatibility check lists what your application uses, and Differences what behaves differently.
Why can a user not see a form, a button or a field?
Rights: the form must be in the user's access level (with the button), and field data access may hide a field. Check it with Acting as another user.
Where do I put code that should run for every form?
JavaScript and CSS: Setup code. PHP: the global hooks nu_before_save / nu_before_edit (Hooks).
How do I make a form work on phones?
Switch its layout from absolute to automatic or grid in the form builder. See Phones and small screens.
How do I change a live form without disturbing users?
Work in a draft, preview it, then publish.
Who changed this record?
The form info (ⓘ) shows created / last changed; the audit trail shows every change.
Does nuBuilder Next send data to an AI?
No. Forms with AI and the prompt generator build a prompt that you copy into an AI tool yourself (AI).
How do I update?
Start page → Update, or php cron.php update on the command line. A backup is made first. See Updating.
A page looks old after an update.
See Troubleshooting – usually not all files were replaced, or PHP's OPcache needs a reload.
