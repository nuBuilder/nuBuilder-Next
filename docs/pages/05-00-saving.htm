Saving data

What happens to a record between the Save button and the database – and what is recorded about it.

For: Users with rights on: nudebug, nuform, nunextaudit, nunextlog, nuprocedure

A save in nuBuilder Next writes only the fields the user changed, checks that nobody else changed the same fields meanwhile, runs your hooks, writes the record and its sub-form rows in one transaction and records every change. Each of these steps is described on its own page:

  • How a save works – the steps on the server.
  • Validation and business rules – what is checked and how to add your own rules.
  • Procedures and hooks – the PHP that runs around a save.
  • Record log, audit trail and debug results – what is recorded.
