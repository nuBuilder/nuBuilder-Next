Troubleshooting

Common problems and their fixes.

For: Administrators (globeadmin, admin roles)

  • Old layout or buttons after an update: not all files were replaced, or OPcache needs a reload.
  • Mails don't arrive: E-mail → Test mail shows the server conversation; check the e-mail log for errors.
  • "Illegal mix of collations": tables created by hand with another collation than nuBuilder Forte's tables – align the collation.
  • Editor field shows HTML code: TinyMCE is not installed – Update → Libraries.
  • phpMyAdmin says "Please log into nuBuilder Forte": open it again from the user menu (the login ended), or check that nudb/config.inc.php is nuBuilder Forte's version.
  • Icons of old forms missing: an icon that Font Awesome 7 (the bundled fallback) no longer has – set $nuConfigNuBuilderPath or $nuConfigFontAwesomePath to nuBuilder Forte's copy.
