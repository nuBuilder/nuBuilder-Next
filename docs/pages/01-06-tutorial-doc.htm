Tutorial

The step-by-step introduction for administrators inside nuBuilder Next.

For: Administrators (globeadmin, admin roles)

Tutorial (start page tile in System, user menu, Ctrl+K; index.php?p=tutorial) introduces nuBuilder Next step by step for the globeadmin and users with an admin role. It has three parts – Basics (start page, sample data, forms and lists, users, access levels, permission items, acting as a user, admin roles), Building applications (forms and design mode, object types, code and hash variables, procedures, reports, dashboards, e-mail, branding, import and export) and Administration (configuration, settings, security, logs, updates and backups, system status, cron, App cloner, REST API, demo mode, migrating a nuBuilder Forte (4.x) application) – and comes in three versions (below). The text is English, like this documentation.

  • Basic and Advanced: on first opening the tutorial asks which one – Basic (the essentials of the three parts) or Advanced (every lesson, plus the part In depth: event order, code functions and debugging, global code, page forms, forms with AI, drafts, data access, concurrent edits, audit trail, notifications, custom user fields and additional access levels, library packs and the File Manager, updates from GitHub and the command line, self-test). Lessons only in the advanced version carry the badge Advanced. The buttons Basic / Advanced at the top switch at any time; a lesson done counts in both, and the choice is kept with the progress. A link from a basic lesson to an advanced one opens it with a note and Switch to Advanced.
  • Coming from nuBuilder Forte: a third, separate tutorial for people who know nuBuilder Forte (4.x) – part What works differently (same database and code, start page and navigation, forms at work, design mode, code, users / rights / settings, reports and SQL builder) and part New in nuBuilder Next (security and sign-in, audit trail / log / notifications, working with data, integration, operation). Its lessons are not in Basic / Advanced; the choice screen offers all three, the buttons at the top switch between them.
  • Each lesson explains one topic; links open the page it is about – or the matching chapter of this documentation – in a new tab, and a Try it box suggests a small exercise (most use the sample data).
  • Done – next lesson marks a lesson; the list on the left and the tile's badge show the progress. Start again clears it. The progress is kept per person: the globeadmin's in zzzzsys_nunext_setting (tutorial_ga), other users' in their sus_json (NUNEXT_TUTORIAL), demo users' only for the session.
  • Users with an admin role see only the lessons of their rights.
  • The start page shows a note with Start the tutorial until it is hidden (Hide, or the button on the tutorial's overview) or every lesson is done; right after the setup wizard it is shown once more, and the wizard's last page links to it.
