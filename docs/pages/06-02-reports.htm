Reports and the report designer

PDF reports in nuBuilder Forte's format, designed and run in nuBuilder Next.

For: Users with rights on: nubuildreport

Forms → Tools → Reports (or the Reports tile): PDF reports – nuBuilder Forte's reports (zzzzsys_report) in the same format, so a report works in nuBuilder Forte (4.x) and in nuBuilder Next, whichever made it. The PDF is written by TCPDF, the library nuBuilder Forte uses: nuBuilder Next takes nuBuilder Forte's copy (<nuBuilder Forte>/third_party/tcpdf, found automatically when nuBuilder Next is a subfolder of nuBuilder Forte), or <nuBuilder Next>/third_party/tcpdf, or the folder in $nuConfigTCPDFPath. Without it the pages say so.

  • Report: code (used by nuRunReport('code')), description, group, data source and an optional launch form. Data sources, as in nuBuilder Forte: a procedure that creates the table #TABLE_ID# (e.g. nuRunQuery("CREATE TABLE #TABLE_ID# SELECT …")), a query of the SQL builder, or a table / view. Every hash variable that is not a column is added to each row (nuBuilder Forte's criteria) – so the fields of the form that starts the report can be printed and used in the SQL (#cus_country#).
  • Launch form: with one, the report opens that form first (the criteria), with a Run report button; without, the PDF comes right away.
  • Access levels: users may run the reports ticked for their access level (zzzzsys_access_report); the globeadmin runs every report.
  • Running: a run object of type Report (button: PDF in a new tab; method iframe: the launch form or the PDF inside the form), the PDF button in the list, index.php?p=report&c=code, and in JavaScript nuRunReport(code[, iframeId]), nuRunReportSave(code, tag, callback(filename, id), fileName) (writes the PDF to the server's temp folder and nuBuilder Forte's table pdf_temp, e.g. to attach it to an e-mail in PHP), and – new in nuBuilder Next – nuPreviewReport(code) (the PDF in a dialog) and nuEmailReportPDF(code, to, subject, body, fileName, callback) (sends the PDF as attachment with the e-mail settings). The form's values are the criteria.
  • Usage and History as for procedures; a report that run objects use cannot be deleted. A procedure that a report prints from shows the report under its usage.

Report designer

Designer opens the layout: the page with its bands top to bottom – report header (once), page header (every page), the headers of the sort groups, detail (each row), the group footers, page footer and report footer.

  • Fields (left): the columns of the data source and the launch form fields – drag them onto a band, or double-click to add them to the selected band. Below: page numbers (#page#, #pages#), code, description, date, user, and the images of Files.
  • Objects: field, text, box, line and image (toolbar). Drag them – also into another band –, resize with the handles, select several with Shift-click or a frame, then align, make the same size or distribute them. Arrow keys move (Shift 4 mm, Alt 0.25 mm), Ctrl+Z / Ctrl+Y undo and redo, Ctrl+C / Ctrl+V / Ctrl+D copy and duplicate, Del deletes, Ctrl+S saves.
  • Properties (right): content, summary (SUM(column), AVERAGE(a, b) = sum a / sum b, per sort group), format (nuBuilder Forte's formats), font, size in points, bold / italic, alignment, colors, border, position and size in mm, minimum / maximum lines (fields grow by lines; minimum −1 hides an empty field), layer. A band has its height, a page break and a designer color.
  • Report tab: paper (A4, A5, Letter, Legal), orientation, fields contain HTML, and up to five sort groups (field, ascending / descending, order) – each with a header and a footer band, printed when the value changes.
  • Texts may contain hash variables; a value starting with #B#rrggbb| or #F#rrggbb| gets that background / text color (conditional formatting from the data source, as in nuBuilder Forte). A box is nuBuilder Forte's KEEP EXACT HEIGHT label.
  • Preview prints the current layout (also unsaved) with empty criteria. The layout is stored in nuBuilder Forte's format (positions in pixels, 4 px = 1 mm), so nuBuilder Forte's designer can open it too.

The sample application has two reports: customers by country (from a table) and orders by customer (from an SQL builder query).
