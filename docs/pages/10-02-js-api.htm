JavaScript functions

Overview of the JavaScript of forms, and the UI helpers info bar, tooltips, charts and button spinner.

For: Administrators (globeadmin, admin roles)

Every function with parameters, return value and examples: JavaScript function reference.

About 100 nuBuilder Forte (4.x) functions work unchanged, among them nuGetValue/nuSetValue, nuHide/nuShow, nuEnable/nuDisable, nuSetProperty, nuRunPHPHidden, nuForm, nuPopup, nuMessage, nuSaveAction, nuDeleteAction, nuCloneAction, nuSelectTab, nuAddActionButton, nuHasBeenEdited, TinyMCE functions, nuOpenAce, nuVendorLogin, nuTranslate, nuTranslateToEnglish. New: nuToast(message, type) shows a notice at the bottom right (success, danger, warning, info).

Bootstrap 5 (window.bootstrap) is available to form code as before. Code that should keep working with a later Bootstrap version can use nuBuilder Next's small helper instead: nuBs.modal(el), nuBs.tooltip(el), nuBs.dropdown(el), nuBs.tab(el), nuBs.toast(el, {delay: 3000}), nuBs.collapse(el) (each returns the Bootstrap instance, e.g. nuBs.modal(el).show()) and nuBs.ready().

Unsupported functions are harmless and write a console warning. Script errors of a form are listed for the globeadmin (bug button in the form toolbar).

Info bar (nuInfoBar)

As in nuBuilder Forte: a notification bar at the top or bottom of the window. $.nuInfoBar.info|success|warning|error(message, options), $.nuInfoBar(options), $.nuInfoBar.modal.… (blocks the page, a click outside shakes the bar), $.nuInfoBar.shake(), .shakeLast(), .closeAll(), .updateContent(html), $('#box').nuInfoBar(…). Options: html, type, theme (light|dark), icon, customClass, autoClose, autoCloseDelay, showCloseButton, allowMultiple, hideOnFormClose, shakeOnShow, modal, animationDuration, animationType (slide|fade), slideDirection, shakeDuration, shakeIntensity, position (top|bottom), fixed, zIndex, opacity, closeOnClick, onShow, onClose, onClick, onShake.

In nuBuilder Next several bars are stacked, fixed bars push the page down, auto-close pauses while the mouse is on the bar, Escape closes it; every call returns the bar, $.nuInfoBar.close(bar) and .count() are extra. Forms open as new pages, so a bar disappears with its form – with hideOnFormClose: false it is shown again on the next page.

$.nuInfoBar.success('Saved!', {autoCloseDelay: 3000});
$.nuInfoBar.modal.warning('Please confirm first');

Tooltip icons (nu-tooltip-icon)

Add the HTML attribute nu-tooltip-icon="text" (HTML allowed: b, i, br, ul, li, code, a …) to an object – a help icon appears on its right; hover, focus or tap shows the text. Per object: nu-tooltip-position (top, bottom, left, right), nu-tooltip-theme (light, dark, blue, green, purple, red, orange), nu-tooltip-arrow-size (small, default, large). nu-tooltip="text" puts the tooltip on the field itself, without icon.

No JavaScript needed – fields added later are found by themselves. nuAttachToolTip(options), nuAttachToolTip.refresh(), .destroy() as in nuBuilder Forte; function nuOnToolTipIcon(element, settings) changes the settings of single fields (theme, iconSize, gapRight, tooltipPosition, animationDuration, iconClasses, onClick(el, text)), nuOnToolTipIconClick(element, text) is called on a click.

Charts (nuChart)

Chart objects call it by themselves; in code: nuChart(chartId, chartType, dataArray, chartTitle, xAxisTitle, yAxisTitle, seriesType, isStacked, options) – chart types of Google Charts (PieChart, ComboChart, BarChart, LineChart, ColumnChart …). dataArray: the name of an array, the array itself, a function or a DataTable; options (extra in nuBuilder Next) are merged into the Google options. Returns a Promise with the chart wrapper, also in window[chartId + '_wrapper']; function nuChartOnReady(chartId, wrapper) is called when it is drawn.

Charts follow light / dark mode, are drawn when a hidden tab opens and redrawn when their size changes. Data from the database: in Before Edit, e.g. nuAddJavascript('window.myData = ' . json_encode($rows) . ';'); and myData as the JavaScript array of the chart.

Button spinner (nuButtonLoading)

nuButtonLoading(button, true) shows a spinner on a button and disables it while something runs, nuButtonLoading(button, false) ends it; nuButtonLoading(button, true, 15) enables it again after 15 seconds. button: id, element or jQuery (also $('#id').nuButtonLoading(true)). Works on Run buttons and on input objects of type button; the width stays the same.

nuButtonLoading('btn_export', true);
nuRunPHPHidden('export_orders');   // the procedure ends it: nuAddJavascript("nuButtonLoading('btn_export', false);")

Badges in a browse column (nuBrowseStyleBadge)

nuBrowseStyleBadge(column) shows the values of a browse column as badges, as in nuBuilder Forte. nuBuilder Next adds an optional second parameter with colours by value (nuBuilder Forte ignores it and draws its plain badge, so the form keeps working there). Put the call in the form's JavaScript (browse). Without code, design mode gives a list column the same badge: Show as badge, with colour rules.

  • A map for exact values: {open: '#cfe2ff', closed: {bg: '#d1e7dd', color: '#0f5132'}}.
  • A list of rules: the first rule that matches wins. Tests: equals, contains, startsWith, endsWith (text), regex, test: (value, row) => … (row = the texts of the row by column number), default: true. What to set: bg, color, border (any CSS colour, or '$value' = the cell's value as colour), class (e.g. text-bg-danger, follows dark mode), label (other text – the value stays the tooltip), icon (Bootstrap Icons name), title, badge: false (plain text). ignoreCase: true per rule, or as third parameter for all.
  • Values no rule matches keep the plain badge. With only bg the text colour is chosen for contrast. An invalid colour is left out; the text is always shown as text.
nuBrowseStyleBadge(3, [
  {equals: 'abc', bg: '#d4edda', color: '#155724'},
  {contains: 'urgent', bg: '#FAA'},
  {test: (v) => Number(v) > 100, bg: '#fff3cd', title: 'over 100'},
  {equals: '1', label: 'Active', icon: 'check-circle', class: 'text-bg-success'},
  {default: true, bg: '#eee'}
], {ignoreCase: true});
