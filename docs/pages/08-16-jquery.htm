jQuery version and jQuery 4

Advanced Which jQuery the form pages load, and how to prepare your application for jQuery 4 with jQuery Migrate.

For: Administrators (globeadmin, admin role right Global code)

Settings → Code → jQuery sets the jQuery of the form pages – nuBuilder Forte (4.x) form code relies on it. nuBuilder Next's own pages do not use jQuery, and its form runtime works with jQuery 3 and jQuery 4. Changing the setting asks for the password again.

Version

  • 3.7.1 (bundled) – the default, the jQuery of nuBuilder Forte 4.9.
  • 4.0.0 (bundled) – ships with nuBuilder Next.
  • Own file – copy a jquery.min.js (for example a newer 4.x from jquery.com) into the folder custom/jquery/ on the server, with FTP or the File Manager. Updates of nuBuilder Next never touch that folder. The page lists the files with the version read from their first line; jQuery Migrate files are recognised and not offered. If the chosen file disappears, the form pages fall back to the bundled 3.7.1 and the page shows a warning.

jQuery Migrate

nuBuilder Next bundles jQuery Migrate 3.6.0 (for jQuery 3) and 4.0.2 (for jQuery 4); the one that matches the chosen version is loaded right after jQuery.

  • Off – no Migrate.
  • Warnings – the debug build. On jQuery 3.7.1 it reports everything jQuery 4 removes, so you can prepare while still on the old version; on jQuery 4 it reports what changed. Messages appear in the browser console and are collected per form in jQuery Migrate messages on the same page (each message once per form, with how often it came; Clear list starts again).
  • Restore removed functions – the production build on jQuery 4: functions such as $.trim work again, without messages. A short-term help for old code, not a permanent setting.

Test as globeadmin

Under Test as globeadmin pick another jQuery and / or switch on jQuery Migrate with warnings for me: only the globeadmin gets it, all other users keep the settings for everyone. That way jQuery 4 can be tried on the live forms first.

Moving to jQuery 4

  1. Open the Compatibility check: point J4 lists the places in your JavaScript that use functions jQuery 4 removed ($.trim, $.isArray, $.parseJSON, $.type, $.isFunction, $.now …) or that Migrate warns about (.toggleClass() without a class name, .unbind(), .delegate() …). Replace them: s.trim(), Array.isArray(x), JSON.parse(s), typeof x, Date.now().
  2. Switch Migrate to Warnings (for yourself under Test as globeadmin, or for everyone) and work with the forms for a while; fix what the list shows.
  3. Choose jQuery 4.0.0 for yourself, still with warnings, and test again. Also check code that loads scripts with $.ajax / $.getScript: jQuery 4 runs fetched scripts only with dataType: "script".
  4. Switch everyone to jQuery 4, then set Migrate to Off. Clear the list and keep an eye on it for a few days with warnings on.

Upgrade guide of the jQuery team: jquery.com/upgrade-guide/4.0.
