Form cloner (copy a form)

Copying a form with its objects and code.

For: Administrators (globeadmin, admin roles)

Admin tools → Form cloner (start page, group Data), or Forms → Tools → Form cloner copies a form – as nuBuilder Forte's Cloner:

  • What: the form with its browse columns and PHP (Before Browse, Before Save …), the chosen tabs with their objects, events and object PHP (e.g. lookup After Browse); optionally its subforms and iframe forms (each copied once, the copied objects point to the copies – the original stays untouched) and the access level rights.
  • Where: as a new form (code and description can be changed; default code_clone_1, the first free number) or into an existing form – the tabs come after its own, object ids that exist there get _2, _3 … (listed afterwards).
  • Only create SQL (ticked by default – untick it to clone in this database): instead of cloning, the INSERT statements are shown to copy or download (optionally with the same primary keys, REPLACE INTO and notes). SQL for chooses the database the statements are written for – MySQL / MariaDB or Microsoft SQL Server (T-SQL: N'…' texts, no REPLACE INTO); it starts with the kind this installation runs on, and the first line of the dump names it – e.g. to move a form to another database.
  • Which forms: the source list holds the application's forms. nuBuilder Forte's own forms (ids starting with nu) appear only after Also show nuBuilder Forte's own forms – a copy keeps their code, which often works only inside nuBuilder Forte. Forms built into nuBuilder Next (the File Manager) and the rights entries of nuBuilder Next's own pages are not offered; the destination list never shows nuBuilder Forte's forms.
  • Everything runs in one transaction: an error changes nothing. The copy uses the same table as the source. The result links to the new form and the form designer; the form history and the Log record it.
  • Saved settings: the Form cloner opens with a list of saved settings (with a search once there are more than ten) – Add opens a new one, Save keeps source form, destination, tabs, subforms, iframe forms and the options; Clone opens a copy that is stored with Save, Delete removes them. They are stored in the table zzzzsys_cloner (shared with nuBuilder Forte) – the same settings nuBuilder Forte's Cloner opens, and the other way round. Clone / Create SQL work with the values on the page, saved or not. The code of a new form is not saved – a free one is suggested each time.
