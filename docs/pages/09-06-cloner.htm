Form cloner (copy a form)

Copying a form with its objects and code.

For: Administrators (globeadmin, admin roles)

Admin tools → Form cloner (start page, group Data), Forms → Tools → Form cloner, or the copy button of a form in the list copies a form – as nuBuilder Forte's Cloner:

  • What: the form with its browse columns and PHP (Before Browse, Before Save …), the chosen tabs with their objects, events and object PHP (e.g. lookup After Browse); optionally its subforms and iframe forms (each copied once, the copied objects point to the copies – the original stays untouched) and the access level rights.
  • Where: as a new form (code and description can be changed; default code_clone_1, the first free number) or into an existing form – the tabs come after its own, object ids that exist there get _2, _3 … (listed afterwards).
  • Only create SQL (ticked by default – untick it to clone in this database): instead of cloning, the INSERT statements are shown to copy or download (optionally with the same primary keys, REPLACE INTO and notes) – e.g. to move a form to another database.
  • Everything runs in one transaction: an error changes nothing. The copy uses the same table as the source. The result links to the new form and the form designer; the form history and the Log record it.
  • Saved settings: the Form cloner opens with a list of saved settings – Add (or the copy button of a form) opens a new one, Save keeps source form, destination, tabs, subforms, iframe forms and the options; Clone copies them, Delete removes them. They are stored in nuBuilder Forte's table zzzzsys_cloner – the same settings nuBuilder Forte's Cloner opens, and the other way round. Clone / Create SQL work with the values on the page, saved or not. The code of a new form is not saved – a free one is suggested each time.
