Sign-in methods

Advanced Password, two-step login, shared login with nuBuilder Forte (4.x), links and tokens – all ways into nuBuilder Next in one place.

For: Administrators (globeadmin, admin roles)

MethodHow it worksSwitched on by
PasswordLogin name and password of zzzzsys_user; the globeadmin's from nuconfig.php. Minimum length $nuConfigPasswordMinLength; the procedure nu_check_password_policy can add rules.always
Two-step login (2FA)After the password: a code from an authenticator app, or a 6-digit code by e-mail when no app is set up. "Remember this device" skips it for $nuConfig2FATrustDays days.$nuConfig2FAAdmin, $nuConfig2FAUser + the access level's "Use two-factor authentication"
Forgot passwordA link by e-mail, valid for 60 minutes and once.always (needs working e-mail and $nuConfigBaseURL)
Shared loginA user already signed in to nuBuilder Forte on the same domain is signed in to nuBuilder Next.$nuConfigSharedLogin = true
Auto-login linknuBuilder Forte's link index.php?u=<login>&p=<hash>, optionally opening a form and record. Links that expire can be made in the user form.$nuConfigAutoLogin = true (see Configuration)
Demo usersSign in read-only.$nuConfigDemoUser (see Demo mode)
REST APIClients get short-lived access tokens (OAuth 2.0 client credentials); no interactive login.$nuConfigApi = true (see REST API)

Rules for every method

  • Expired or locked accounts are refused; a user who must change his password is asked to right after signing in.
  • Failed logins are rate-limited and written to the log; the procedure nu_invalid_login can replace the message, nu_startup runs after every login and can refuse it.
  • Sessions end after $nuConfigSessionTimeout / $nuConfigSessionTimeoutGlobeadmin minutes without activity, when the password is changed anywhere, or when the globeadmin ends them.
  • The globeadmin can reset a user's two-step login (lost phone) in the user form.
