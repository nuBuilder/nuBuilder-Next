Migrating from nuBuilder Forte 4.9

Running an existing nuBuilder Forte (4.x) application in nuBuilder Next.

For: Administrators (globeadmin, admin roles)

nuBuilder Next works on the database of a nuBuilder Forte 4.9 application without converting it. Forms, rights, procedures and reports stay where they are, and nuBuilder Forte can keep running on the same database while you check the application in nuBuilder Next.

  1. Back up the database.
  2. Install nuBuilder Next, ideally as a sub-folder of nuBuilder Forte (e.g. /nubuilder4/nunext/), so it finds nuBuilder Forte's nuconfig.php and libraries (Installation). An existing nuBuilder Forte database must be allowed with $nuConfigAllowExistingNuDB.
  3. Run the Compatibility check: it scans all code of the application for nuBuilder Forte functions and shows whether each is supported.
  4. Read the differences for the functions your code uses.
  5. Test on a copy first – the App cloner makes one.
  6. Optional: switch forms to the automatic layout to make them work on phones.

The tutorial has a lesson on this (Tutorial).
