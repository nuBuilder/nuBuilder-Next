Database table reference

The tables nuBuilder Next reads and writes, with their purpose.

For: Administrators (globeadmin, admin roles)

Read-only reference; change system tables through the screens of nuBuilder or nuBuilder Next, not by hand. Columns are best looked up with Inspect record or the database tools.
