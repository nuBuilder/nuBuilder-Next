Lists (browse)

Searching, sorting, filtering, paging, printing and exporting lists.

For: Everyone

  • Search: type into the search field and press Enter. Several words must all match. Dates are found as they are displayed. As in nuBuilder, "two words" in double quotes are searched together, and a minus leaves rows out: GmbH -Berlin, -"on hold". Accents and case do not matter (cafe finds Café). The words found are highlighted in the list – in form lists only in the columns that are searched, in nuBuilder Next's own lists in every column; form code can mark other text with $(…).nuHighlight(…) (colour: CSS variable --nu-highlight, elements with the class nuNoHighlight are left out). Back to all records: the button right of the search (shown while a search or a column filter is active, also in form lists) removes the search words and column filters – sorting, rows per page and a filter set by form code stay; Esc in the search field and the browser's × in the field remove the search words and show the list again at once. On a computer the cursor is already in the search field of nuBuilder Next's own lists (Users, Access levels, Forms …).
  • Same look everywhere: browse lists of your own forms look like nuBuilder Next's lists – the search field (350 px, search button on the right) sits inside the list card, the table has the same header and row height. Form code keeps working: #nuSearchField, #nuSearchButton, #nuBrowseTable, nuHideSearchField(), nuDisableSearchField().
  • Users list: columns Position (after Department / Team) and Code (after Login name), both sortable; filter Position (all, one position or "(no position)").
  • The users list has no row buttons: open the user to clone, archive or delete them. The access levels list has only a Clone button in the rows (hidden below 768 px); delete an access level on its page.
  • Forms list: filter Group (all, one group or "(no group)"); the column Status shows nuBuilder's form status (Active, Draft, Archived – set in the form builder). By default archived forms are hidden (filter Status: All except archived); choose All or one status to see them.
  • Filters of nuBuilder Next's own lists (group, status, type, dates …) are hidden behind the filter button (funnel) right of the search field; they stay open while a filter is set, and the × button resets search and filters. In the users list they are shown at once on screens at least 800 px wide.
  • Form info (globeadmin only): next to Delete (before the layout buttons) shows the form's title, code, description, type, form ID, table, primary key and browse SQL – in a record also its ID and, from the audit trail, when it was created and last changed (and by whom; not in the audit trail when nothing was recorded). copies one value, Copy all everything as “Label: value” lines. Esc or a click outside closes it.
  • Sort: click a column title; click again to reverse the order.
  • Filter: some columns have a filter list above them.
  • Open a record: click the row. Add creates a record (if you have the right). The buttons of a list or record (Add, Print, Save, Clone, Delete …) sit right after its title, so they stay close on wide screens.
  • Pages: below the list, the total number of records; when the records fill more than one page also Back / Next and the page size – a list that fits on one page shows only the total. With several pages, click the page size (e.g. 50 per page) to show 10, 25, 50, 100, 250 or 500 rows – the choice stays while you page, sort and search in that list (it is in the address, per=); opened again from the menu, the list uses its own size again. Phones show no page size. The forms list shows up to 500 forms per page (list view Default), so the pager appears there only from the 501st form. Back / Next change the page; click Page x / y, type a page number and press Enter to jump there (Esc cancels).
  • Export / print (if you have the print right): a print view of the current list in a new tab, with Export CSV there (opens in Excel) – search, sort and filters apply. In the print view of the system lists the × after a column title hides that column (for printing and Copy); Undo shows the last one again, Reset view all of them – the browser remembers the hidden columns per list.

Print and CSV

Lists (form browse lists and nuBuilder Next's own lists such as Users, Access levels, Log, Files …) have a Print button when your access level has the right Print on the matching form. As in nuBuilder it opens the list as a table in a new tab – with the current search, filters and sort and all rows, not only the page you see (up to 5,000).

  • Copy puts the table on the clipboard – it pastes as a table into Excel, Word or an e-mail (as tab-separated text into plain-text fields). To print, use the browser's print command (Ctrl+P).
  • Export CSV asks for the delimiter (semicolon, comma, tab, pipe; default $nuConfigCSVSeparator), the file name, whether the first row holds the column titles and whether the file starts with a UTF-8 BOM (so that Excel shows umlauts correctly) – then the download starts (up to 50,000 rows). Your choices are remembered in this browser.
