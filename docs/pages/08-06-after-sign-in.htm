Which page opens

  1. A link the user followed while signed out (for example an e-mail with a record) opens first, after sign-in.
  2. globeadmin: the form of the setting $nuConfigGlobeadminHome when one is set, else the administrators' tile page.
  3. Everyone else: the Home form when the access level's start page is Home form. As in nuBuilder Forte, users may open their Home form even when it is not in the access level's form rights – then without Add, Save, Delete, Clone and Print. Admin forms (users, access levels, forms, procedures, SQL, setup) are never opened this way. Otherwise the tile page: users with an admin role get the administrators' tile page, all others the tile page of their access level (its own, else the default for all access levels, else the automatic one).

When a form opens instead of the tile page, the user menu shows Tile page, so the tiles stay one click away. On a database set up in nuBuilder Next the default is Tile page, so nothing changes until an access level is switched. On a database that comes from nuBuilder Forte, every access level with a Home form starts on it, as in Forte – set once when nuBuilder Next is installed on the database or updated (levels of the sample applications excepted), and a new access level with a Home form starts on it too; switch a level to Tile page on its tab Start page.

The breadcrumb then starts with the Home form instead of Home, as in nuBuilder Forte: on the Home form itself there is no extra step, on a form opened from it the first step leads back to the Home form.

nuBuilder Forte always opens the Home form. In nuBuilder Next the access level's choice is kept in nuBuilder Next's own settings (row start_page); nuBuilder Forte's tables are not changed.

All Home forms at a glance

The globeadmin finds every start page of the access levels in one panel: the ▾ next to the Home button (with a logo in the top bar: the house button right of the logo). Without a logo, a right-click on the Home button – or a long press on a phone – opens the same panel; a plain click still goes Home. It has two tabs, Home forms and Tile pages; the panel opens on the tab you used last. User Home (and its pencil for design mode) sits in the head of the panel, next to the title, so it is one tap away on both tabs – it is not repeated in the list.

Home forms: each row shows the form's title and the number of access levels that have it as their Home form; a click on the title folds out its code and those access levels (a search folds out the rows it finds). A solid chip means the level starts on this form; a dashed chip means the level starts on the tile page. Click a chip to open the access level on its Start page tab; the blue button at the right (Open) shows the form and the pencil (Design) opens it in design mode.

Tile pages: the first row is the default tile page of users – the access levels without a tile page of their own (Automatic tile page while no default has been saved). Then comes every saved tile page with the access levels that use it. A chip opens that level's tile page in the editor, Open the tile page itself (see Tile pages of users). Your own tile page as globeadmin is the Home button itself.

The search field finds a form, a tile page or an access level in the tab that is shown.

A Home form that no longer exists is not listed either. nuBuilder Forte's empty form nublank is not listed: access levels that start on it get an empty page on purpose (technical accounts). Elsewhere – the access levels list and the Home form field – it is shown as Blank page (system).
