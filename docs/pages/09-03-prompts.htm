AI: prompt generator and forms with AI

Building prompts for AI tools; nuBuilder Next itself never calls an AI.

For: Users with rights on: nupromptgenerator

Forms → Tools → Prompt generator (also a start page tile; rights on nuBuilder Forte's form nupromptgenerator) builds a prompt for an AI tool – nuBuilder Next does not call any AI, you copy the prompt. Prompts are stored in nuBuilder Forte's table zzzzsys_prompt_generator (created if missing), so they are shared with nuBuilder Forte (4.x).

  • Prompt: what the AI should do. Languages, Scopes (where the code runs: procedure, Before Save …) and Topics add short nuBuilder Forte notes and wiki links; Tables add the column list with types and keys (no data, at most 15 tables).
  • The magic-wand button suggests topics, languages and scopes from words in the prompt (English and German), e.g. "before save" → PHP Before Save, "2FA" → Two Factor Authentication.
  • Instruction (first field) is the general instruction at the top of the prompt. Complete prompt updates while you type: instruction, context, then the request at the end. Copy prompt puts it on the clipboard; the counter shows the number of characters.
  • Code is only needed to save. Template marks a reusable starting point (filter in the list); Clone copies a prompt.
  • Prefill by link: index.php?p=prompts&id=new&table=…&scope=…&lang=… (comma-separated codes).
