AI: prompt generator and forms with AI

Building prompts for AI tools; nuBuilder Next itself never calls an AI.

For: Users with rights on: nupromptgenerator

Forms → Tools → Prompt generator (also a start page tile; rights on nuBuilder Forte's form nupromptgenerator) builds a prompt for an AI tool – nuBuilder Next does not call any AI, you copy the prompt. Prompts are stored in the table zzzzsys_prompt_generator (shared with nuBuilder Forte) (created if missing), so they are shared with nuBuilder Forte (4.x).

  • Prompt: what the AI should do. Languages, Scopes (where the code runs: procedure, Before Save …) and Topics add short notes and links to nuBuilder Next's function reference, documentation pages and source files on GitHub (the state of the last published version), plus the matching page of the nuBuilder Forte wiki, which mostly applies too; Tables add the column list with types and keys (no data, at most 15 tables).
  • The magic-wand button suggests topics, languages and scopes from words in the prompt (English and German), e.g. "before save" → PHP Before Save, "2FA" → Two Factor Authentication.
  • Each chosen table is described in full, so the AI need not guess: every column with type, NOT NULL, default, key and comment; then – only where they exist – a primary key over several columns, unique keys, indexes over several columns, foreign keys with their delete / update rule and the tables that refer to this one, CHECK constraints, generated columns, triggers, the table comment, the approximate number of rows (from 1,000), and for a view its SELECT. Because nuBuilder applications rarely declare foreign keys, the relations nuBuilder itself knows are listed too: the forms on the table with their primary key, lookups (which column points at which table) and sub-forms (child table and its link column) – in both directions. No data rows are included.
  • Instruction (first field) is the general instruction at the top of the prompt. Complete prompt updates while you type: instruction, context, then the request at the end. Copy prompt puts it on the clipboard; the counter shows the number of characters. Download context (as in Form with AI) makes a file to attach to the chat together with the prompt: the PHP and JavaScript functions, hash variables and guide of this installation, the forms by code and the structure of the chosen tables (all tables when none is chosen) – no data; ▾ offers a zip and the full reference.
  • Code is only needed to save. Template marks a reusable starting point (filter in the list); Clone copies a prompt.
  • Prefill by link: index.php?p=prompts&id=new&table=…&scope=…&lang=… (comma-separated codes).
