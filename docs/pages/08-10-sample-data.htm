Sample data

A small sample application for trying things out.

For: Administrators (globeadmin, admin roles)

Admin tools → Sample data (index.php?p=sample) installs a small sample application for trying out and testing nuBuilder Next (and nuBuilder – the forms are stored in nuBuilder's format and open there too).

  • Forms (codes sample_…, ids without underscore such as sampleorder, because nuBuilder splits hook ids like sampleorder_BS at "_"): sample_home (launch form, start page of the sample access levels), sample_customer (nuBuilder positions, two tabs, validation, Before Delete check), sample_product (grid layout), sample_order + sample_order_item (auto layout, audit columns, lookup, grid subform, calc, Before Edit / Before Save / After Save PHP) and sample_all + sample_all_line – every object type and input type with different formats, access settings (read only, hidden, globeadmin only), events, an iframe and a subform in form layout. Its tabs Run and Subform show the run object types and the subform; Charts three charts, Miscellaneous tooltip icons, the info bar and button spinners. The charts get their data (from the form's JavaScript, from the database via Before Edit, and in the object). Upload has a file object with the target File System: files are uploaded with Uppy into the folder nu_uploads/ next to the web root by nuBuilder's procedure nu_upload_file_template (needs the library pack Uppy).
  • Users and access levels: sample_anna (view only), sample_ben (add and change, German), sample_carla (everything), sample_dario (orders only, must change the password), sample_eva (two-factor login, expires in a year). Passwords are random and shown once; New passwords creates new ones.
  • Also: 9 formats, 2 procedures (window / hidden), an e-mail template, 3 code snippets, a picture in Files, and two reports (customers by country from a table, orders by customer from the SQL builder query sample_orders) – started from tiles on the start page and from All objects; every sample access level may run them.
  • Start pages of users (version 15): sample_sales, sample_manager and sample_editor have their own tile start pages – see Start pages of users (examples).
  • Tables sample_customer, sample_product, sample_order, sample_order_item, sample_all, sample_all_line with data (InnoDB).

Remove deletes every sample record (ids starting with sample_ and the sample form ids), rights of other access levels on sample forms and the sample tables. It is blocked while a non-sample user has a sample access level. A newer nuBuilder Next may bring a newer sample set: the page then shows update available – Refresh removes and installs it again (changes to sample records are lost).
