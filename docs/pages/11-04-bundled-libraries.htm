Bundled libraries

Third-party libraries that come with nuBuilder Next and that your code may use.

For: Administrators (globeadmin, admin roles)

These libraries are part of the nuBuilder Next package (vendor/bundled/) and are always there. The exact versions are listed in vendor/bundled/libraries.json and on Update → Libraries.

Your form code may use jQuery, Bootstrap, Tom Select and ApexCharts. Larger libraries (TCPDF, PHPMailer, TinyMCE, phpMyAdmin, Adminer, Uppy …) are not in the package – they come from nuBuilder Forte's folder or as library packs.

Source maps: the .map files of minified libraries are not shipped. So the browser's developer tools do not ask for them (and report a Content-Security-Policy error), the sourceMappingURL comment is removed from such files – in the package, during an update and when a library pack is installed. A comment whose .map file is delivered stays. Library packs installed earlier are cleaned when they are installed again.
