Bundled libraries

Third-party libraries that come with nuBuilder Next and that your code may use.

For: Administrators (globeadmin, admin roles)

These libraries are part of the nuBuilder Next package (vendor/bundled/) and are always there. The exact versions are listed in vendor/bundled/libraries.json and on Update → Libraries.

Your form code may use jQuery, Bootstrap, Tom Select and ApexCharts. Larger libraries (TCPDF, PHPMailer, TinyMCE, phpMyAdmin, Adminer, Uppy …) are not in the package – they come from nuBuilder's folder or as library packs.
