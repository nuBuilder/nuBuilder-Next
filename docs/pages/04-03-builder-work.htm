Working in the form builder

Arranging objects, properties, history and the code editor.

For: Users with rights on: nucodesnippet, nuform

  • Above the work area: the views Form settings (description, code and type are required – marked with * – plus table, layout and the form's Tabs: titles, visibility, order, saved with the settings), Browse (the list: browse SQL, rows per page, the form that opens records, and the columns – not for edit and launch forms), Objects, Code and History, and on the right Start draft (its (i) explains drafts) or the bar of an open draft. The open view is in the address (#objects, #form …) and comes back after a reload. Objects shows the objects per tab on the left (reorder with the arrows), the chosen object in the middle and the preview on the right; the other views have no objects list – the middle card and the preview share the width, Code gives the editors the larger part – drag the bar between code and preview (or use the arrow keys on it) to change it, a double-click goes back to the default; the width is remembered in this browser. On Code the buttons come in two groups, JavaScript & CSS (Browse & Edit, Edit, Browse, CSS) and PHP (Before Edit … After Delete), a dot marks the ones with code; the editor has no label above it (the buttons name it): its toolbar sits on the left, opens Copy / Paste. On wide screens the preview takes all the extra width. A click on an object in the preview, or Properties… in a form's right-click menu, opens it on Objects.
  • An object's ID / field may contain only letters, digits and _ and must not start with a digit – the field turns red while it does not fit, and spaces at both ends are removed when you leave it. Lists of forms, reports and procedures (lookup form, sub-form form, run form / report, display procedure, Open records in form) are searchable: type part of the code or description.
  • Toolbar below the title: Back | Save · Undo | Clone object · Open form · Change with AI · Data access; Delete object and Delete form sit in their own row below, apart from the others.
  • The Save button (top, next to Undo) turns red while the open panel has unsaved changes. Ctrl+S saves.
  • Preview: click an object to select it; drag to move, corner handle to resize (absolute layout), or drop before/after/into boxes and change the width (auto/grid layout).
  • Several objects (absolute layout, as in nuBuilder Forte's arrange mode): Ctrl/⌘ + click adds or removes an object, dragging on an empty place selects every object the box touches (with Ctrl/⌘ the earlier selection stays), Ctrl/⌘ + A selects all objects of the tab, Esc none. The selection moves together – with the mouse or the arrow keys (5 px, with Alt 1 px); Shift + arrow keys change the width (and the height of objects with a set height). The Arrange panel at the top right of the preview (drag its title row to put it elsewhere – the place is kept in this browser; double-click the title row to put it back in the corner): Up / Down move the objects in the object order (tab order), Top, Bottom, Left, Right align them to the outermost one, Vertical / Horizontal space three or more evenly, Shortest, Tallest, Thinnest, Widest give them the same size. Each step is saved at once (in a draft while one is open) and can be undone with Undo.
  • Preview of a Browse and edit form: Browse | Edit in the preview header – Browse shows the list (browse columns, browse SQL and rows per page, of the draft too), Edit the record in Record. The choice is remembered per form in this browser; the view Browse switches to the list, and Objects back to the record (those automatic switches are not remembered). Browse forms always show the list, edit and launch forms the record; subforms have no preview.
  • Tab order: the button in the preview header puts a red number on every object the Tab key stops at, in that order and over all tabs (a sub-form counts once). Change the order with the ▲ / ▼ arrows in the object list. Click again to hide the numbers; this browser remembers the choice.
  • Undo / History: every change stores the complete form definition (last 100); restore any state. Table changes (new columns) are not undone. Published versions of drafts carry a badge vN and are kept for ever.
  • If an object's ID has no column in the table, the builder offers to add the column.
  • Removing rows (tabs, list columns, events of an object, HTML attributes): crosses the row out and turns Save red; it is removed when you save (attributes: when you click Apply). Until then brings it back.
  • HTML attributes: the button ⚙ next to the field opens the attribute editor – one row per attribute (name with suggestions, value; known attributes get a selection or need no value). It warns about invalid names, duplicates and event handlers (onclick … belong into the object's events). The result is written back as name="value", ….
  • Formats: pick a format, + creates a new one, ✎ edits it.
  • Tabs: only the globeadmin can rename or delete existing tabs (also not through Undo / History). Other users with rights on forms can add tabs, name new ones, change their order and visibility; existing titles are shown greyed.
  • Delete form (in the second row of the toolbar, globeadmin only – other users with rights on forms do not see the button) deletes the form with its objects, tabs, list columns, events, PHP hooks and access rights. The globeadmin can also tick Also delete the table (with the number of records): the button only works after the table name is typed exactly as shown (case matters, pasting is not possible), and the password must have been confirmed in the last minutes. The table is not offered when it is a view, a zzzzsys table or used by another form. Both deletions are logged (Form deleted, Table deleted). A deleted table cannot be restored by Undo – only from a backup.
  • Layouts: absolute (pixel positions as in nuBuilder Forte (4.x) – objects stack as there: in drawing order without a z-index, content boxes behind; an element with z-index: -1 in an HTML object, e.g. a framed box from your CSS, lies behind the other objects), auto (responsive rows derived from the positions) and grid (12 columns). "Convert to grid" writes the auto result as a starting point.

Editing code

Fields that hold code – PHP, SQL, JavaScript, HTML or CSS – are shown in a typewriter font. Double-click such a field to open the code editor: syntax colours, line numbers and a full-screen button. Ctrl+Enter (or Ctrl+S, or OK) takes the code over into the field; Esc or Cancel closes the editor and asks first if you changed something. Save the record afterwards as usual.

The toolbar of every code editor (double-click editor, form builder, procedures) offers Undo / Redo, Search (Ctrl+F, then Enter / Shift+Enter for next / previous), Replace (Ctrl+H), Toggle comment on the selected lines (Ctrl+/), Show spaces and tabs, Full screen (F11, Esc ends it) and Format (Shift+Alt+F). Format tidies PHP, SQL (MySQL or T-SQL), JavaScript, HTML and CSS with the same rules as nuBuilder Forte; hash variables such as #RECORD_ID# are kept unchanged. Code with a syntax error is left as it is and a message names the problem. Undo reverts a format in one step.

Insert (next to the toolbar, in PHP, JavaScript and HTML editors) opens the functions of the function reference – PHP functions in PHP code, JavaScript functions in JavaScript and HTML: search (name, signature or description) and group, and for the selected function its signature, description, parameters, return value, example and sample result (on wide screens to the right of the list, on narrow ones below it). Insert call (Enter) inserts the call with the required parameters and selects the first one to type over; Insert example (Shift+Enter) inserts the example; Help opens the entry in the help. On the procedures page the menu has a second tab Snippets (the code snippets). While typing, functions starting with nu or db_ are suggested after two letters (not in strings and comments) – ↑ / ↓ choose, Enter inserts the call, the box next to the list shows the signature and description; Ctrl+Space suggests for any word.

Copy and paste: click the label of a code field (for example PHP or JavaScript on a procedure; editors without a label, such as the double-click editor and the nuconfig.php editor, have a button in the toolbar) for Copy (the whole code), Paste (at the cursor – a selection is replaced, as with Ctrl+V) and Paste (replace existing) (the clipboard becomes the whole code; Undo brings the old code back). The browser may ask once to allow reading the clipboard. Without HTTPS, or when reading is refused, a small box opens instead: paste the text there and click Insert. Read-only editors offer only Copy.
