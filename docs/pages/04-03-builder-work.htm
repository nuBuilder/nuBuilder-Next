Working in the form builder

Arranging objects, properties, history and the code editor.

For: Users with rights on: nucodesnippet, nuform

  • Left: objects per tab (drag to reorder). Right: the properties of the selected object, form settings, list columns, tabs, code.
  • The Save button (top, next to Undo) turns red while the open panel has unsaved changes. Ctrl+S saves.
  • Preview: click an object to select it; drag to move, corner handle to resize (absolute layout), or drop before/after/into boxes and change the width (auto/grid layout).
  • Preview of a Browse and edit form: Browse | Edit in the preview header – Browse shows the list (browse columns, browse SQL and rows per page, of the draft too), Edit the record in Record. The choice is remembered per form in this browser; selecting Browse (the columns) or the tab Browse of the form settings switches to the list. Browse forms always show the list, edit and launch forms the record; subforms have no preview.
  • Tab order: the button in the preview header puts a red number on every object the Tab key stops at, in that order and over all tabs (a sub-form counts once). Change the order with the ▲ / ▼ arrows in the object list. Click again to hide the numbers; this browser remembers the choice.
  • Undo / History: every change stores the complete form definition (last 100); restore any state. Table changes (new columns) are not undone. Published versions of drafts carry a badge vN and are kept for ever.
  • If an object's ID has no column in the table, the builder offers to add the column.
  • Removing rows (tabs, list columns, events of an object, HTML attributes): crosses the row out and turns Save red; it is removed when you save (attributes: when you click Apply). Until then brings it back.
  • HTML attributes: the button ⚙ next to the field opens the attribute editor – one row per attribute (name with suggestions, value; known attributes get a selection or need no value). It warns about invalid names, duplicates and event handlers (onclick … belong into the object's events). The result is written back as name="value", ….
  • Formats: pick a format, + creates a new one, ✎ edits it.
  • Tabs: only the globeadmin can rename or delete existing tabs (also not through Undo / History). Other users with rights on forms can add tabs, name new ones, change their order and visibility; existing titles are shown greyed.
  • Delete form (in the row of buttons below the title, globeadmin only – other users with rights on forms do not see the button) deletes the form with its objects, tabs, list columns, events, PHP hooks and access rights. The globeadmin can also tick Also delete the table (with the number of records): the button only works after the table name is typed exactly as shown (case matters, pasting is not possible), and the password must have been confirmed in the last minutes. The table is not offered when it is a view, a zzzzsys table or used by another form. Both deletions are logged (Form deleted, Table deleted). A deleted table cannot be restored by Undo – only from a backup.
  • Layouts: absolute (pixel positions as in nuBuilder), auto (responsive rows derived from the positions) and grid (12 columns). "Convert to grid" writes the auto result as a starting point.

Editing code

Fields that hold code – PHP, SQL, JavaScript, HTML or CSS – are shown in a typewriter font. Double-click such a field to open the code editor: syntax colours, line numbers and a full-screen button. Ctrl+Enter (or Ctrl+S, or OK) takes the code over into the field; Esc or Cancel closes the editor and asks first if you changed something. Save the record afterwards as usual.

The toolbar of every code editor (double-click editor, form builder, procedures) offers Undo / Redo, Search (Ctrl+F, then Enter / Shift+Enter for next / previous), Replace (Ctrl+H), Toggle comment on the selected lines (Ctrl+/), Show spaces and tabs, Full screen (F11, Esc ends it) and Format (Shift+Alt+F). Format tidies PHP, SQL (MySQL or T-SQL), JavaScript, HTML and CSS with the same rules as nuBuilder; hash variables such as #RECORD_ID# are kept unchanged. Code with a syntax error is left as it is and a message names the problem. Undo reverts a format in one step.

Copy and paste: click the label of a code field (for example PHP or JavaScript on a procedure; editors without a label, such as the double-click editor and the nuconfig.php editor, have a button in the toolbar) for Copy (the whole code), Paste (at the cursor – a selection is replaced, as with Ctrl+V) and Paste (replace existing) (the clipboard becomes the whole code; Undo brings the old code back). The browser may ask once to allow reading the clipboard. Without HTTPS, or when reading is refused, a small box opens instead: paste the text there and click Insert. Read-only editors offer only Copy.
