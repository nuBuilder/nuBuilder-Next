Navigation and your start page

The menu bar, language and theme, your start page and the side bar.

For: Everyone

The menu bar shows only the areas you have rights for. On phones the menu is behind the ☰ button. The logo (nuBuilder Next) always opens the start page; Start is listed only next to other areas.

  • Language (Deutsch (DE), Deutsch (CH), English (UK), English (Australia), English (US), Français, Italiano, Español, Português, Русский, 简体中文, Nederlands, Polski, العربية): your choice is saved with your user. Arabic is shown right to left. The three English versions differ in spelling (colour / color, customise / customize), the two German versions too (Deutsch (CH): ss instead of ß and «quotes»); the page language (<html lang>: de-DE, de-CH, en-GB, en-AU, en-US) follows the choice, e.g. for numbers in dashboards. nuBuilder's formats (Formats) stay as they are. nuBuilder itself only knows "English" and "German": the user's language stays English / German and the version is kept in the user's JSON (sus_json, NUNEXT_LANG_VARIANT). Without a choice: the installation's default (setup wizard), else the browser's (en-US, en-CA and plain "en" → US; en-AU, en-NZ → Australia; other English → UK; de-CH → Deutsch (CH), other German → Deutsch (DE)).
  • Back (, first button): goes one step up the breadcrumb – from a record to its list, from a form's list to where it was opened (Forms list, start page or another form). All other pages have it too: lists (users, forms, procedures …) go back to the start page or to the page above them in the breadcrumb (e.g. Settings → Admin tools, Procedures → Forms), single records go back to their list.
  • Theme (sun / moon icon): light, dark or automatic (follows your device).
  • User menu (your name, top right): Security, change password, this documentation (in a new tab), sign out.
  • F1 opens the page of this documentation that belongs to the page you are on, in a new tab – on form pages Editing records, on admin pages their own chapter. Pages without a matching chapter (sign-in, the documentation itself) leave F1 to the browser.
  • Globeadmin: the start page shows all areas as tiles in groups; Customise changes what goes where, how the tiles look and which layout is used (see Start page of the globeadmin); + on a tile opens a new record, ▾ a menu with the pages behind it. The user menu also has Admin tools, Database and File Manager.

Your start page

The start page shows tiles for the forms, reports and procedures your administrator set up for your access level. Customise → Appearance (key V) changes how the tiles look – only for you. Customise → Content → Personalise puts a and an on every tile: star your favourites (the next to the search then shows only them) and hide tiles you do not need; they are listed under Hidden by you while you personalise and come back with one click. Done saves, Cancel keeps everything as it was, Back to the standard removes your favourites and hidden tiles. The search field above the tiles filters them as you type (/ jumps into it).

Favourites by right-click: a right-click on a tile (a long press on a phone) shows its name and description and Add to favourites / Remove from favourites – where you may change the favourites of your start page (the globeadmin and admin roles on an editable layout, users on their own page). The same change as the ☆ in the side bar.

Appearance → Favourites / Recently used show your starred tiles and the pages, forms and tiles you opened last as a row of buttons above the groups – Recently used is the same list as in the side bar (kept per user on the server, on every device); ⊗ next to its heading empties it, a right-click on the side bar's list does the same. A tap on the heading of a row folds it (▸, with the number of entries) or opens it again (▾); the state is remembered on this device. On a phone Recently used starts folded.

Side bar: favourites and recently used

An optional column on the left of every page: Favourites – the tiles marked with ☆ on your start page, in the same order – and Recently used – the last 8 pages and forms you opened (a form counts once, whichever record). Switch it on or off for yourself in the user menu (top right) → Side bar; it is off until you or your administrator switch it on.

  • ☆ next to an entry makes a start page tile a favourite or stops it (the start page shows the same change). Forms that are not tiles of your start page have no ☆.
  • The side bar is a drawer on every screen: the button left of the logo opens it; ✕, Esc or a click beside it closes it.
  • A right-click on an entry of Recently used (a long press on a phone) → Remove from recently used takes that one out – in the side bar and in the start page's row. ⊗ next to Recently used – or a right-click on the list → Clear recently used – empties the list (also the start page's row). Entries you no longer have the right to open are not shown. The list is kept on the server per user (table zzzzsys_nunext_recent, the last 10), also while the side bar is off – the start page's row Recently used shows the same list; tiles opened on the start page that lead to no page of their own (reports, links, tools) count too. Demo visitors keep it for the session.
  • The globeadmin sets the default for everybody without an own choice: user menu → Side bar for everyone by default. A user's own choice (in sus_json, key NUNEXT_SIDEBAR) wins.
