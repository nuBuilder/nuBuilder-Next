# Plugins

Each plugin of this installation lives in a folder of its own here: `plugins/<id>/` with `plugin.json`, `plugin.php` and its files.
Plugins are installed, switched on and off and removed on **Update → Plugins** (globeadmin). An update of nuBuilder Next never
changes this folder except this file and `.htaccess`, which keeps the folder closed to the web.

How to write a plugin: Help → Code reference → Plugins.
